# Open-source + paid-cloud landscape for indiehackers and small teams (2025-2026)

Research date: 2026-10-12. All GitHub star counts, creation dates and last-push dates below were pulled from the GitHub REST API on 2026-10-12 via `gh api repos/<owner>/<repo>` (cited as "GitHub API 2026-10-12" with the repo URL). Prices were taken from vendor pricing pages fetched 2026-10-12 unless otherwise dated. Where only third-party aggregator figures were found, that is stated.

Method note: web search budget was exhausted mid-task, so pricing and traction for the smaller products rests on (a) direct fetches of vendor pricing pages, (b) GitHub API data, (c) directory pages (OpenAlternative, awesome-selfhosted README), (d) TrustMRR Stripe-verified revenue pages, and (e) the earlier search summaries. Each "empty category" verdict lists exactly what was searched.

---

## Key Question 1: Which categories have an open-source leader with 10k+ stars AND a healthy paid cloud? (full category-by-category map)

### Takeaway
Roughly 20 of the ~30 categories now have at least one open-source product above 10k stars with a self-serve paid cloud. The strongest "indie-scale" OSS+cloud combinations (big repo, cheap self-serve cloud, public revenue) are social scheduling (Postiz), web analytics (Plausible, Umami, Rybbit), scheduling (Cal.com), link management (Dub), e-sign (Documenso), CRM (Twenty), support (Chatwoot), docs (Docmost), screen recording (Cap), and payments/MoR (Polar). Several large repos have no first-party cloud at all (Uptime Kuma, Gatus, Listmonk, Shlink, Screenity, Keycloak, Better Auth), which is where hosted-wrapper opportunities sit.

### Inferences
- Analytics is the category with the heaviest self-host footprint (ClickHouse everywhere except Umami), which explains why Umami's Postgres-only design and free 100K-event cloud coexist with Plausible/Rybbit paid clouds.

## Key Question 4: Which open-source-plus-cloud indie products launched in 2025-2026 and gained traction fast, and what do they have in common?

### Takeaway
The clearest 2025-2026 indie OSS+cloud successes are Rybbit (analytics, launched April 2025, 13k stars, $9.2k MRR), Postiz's 2025-26 surge (open-sourced Sept 2024, $17k → $260k MRR, solo founder), Cap (23k stars, $8-12 cloud), Better Auth (30k stars, $5M seed, no paid product yet), Polar (10k stars, MoR) and OpenCut (94k stars, no cloud yet). Common traits: a hated incumbent with a per-seat or usage tax, AGPL + a single cheap flat cloud tier ($13-$29), a "self-host free forever" promise, and distribution via GitHub trending, Product Hunt and (in 2026) AI-agent/MCP integrations.

### Cited Findings
- Rybbit: founded Jan 2024, public launch April 15 2025, "10,000 GitHub stars within its first year", Standard $13/mo annual, Pro $26/mo, free self-host AGPL "feature-complete, including session replay and funnels" — [Gappsy](https://gappsy.com/tools/rybbit/); 13,114 stars 2026-10-12 — [GitHub](https://github.com/rybbit-io/rybbit); Stripe-verified $9,215 MRR, 318 subscriptions on 2026-10-12 — [TrustMRR](https://trustmrr.com/startup/rybbit-analytics); Product Hunt Oct 19 2025, 586 upvotes — [hunted.space](https://hunted.space/dashboard/rybbit/launches/rybbit-2).
- Postiz: open-sourced Sept 2024 → "3K to 14K GitHub stars in three months"; "$700/month to $17K MRR" post-open-source; $21K MRR March 2026 → $145K MRR July 2026; "team of one"; growth attributed to open source as distribution plus an agent CLI, MCP server and ClawHub skill after the OpenClaw agent repo went viral — [Superframeworks](https://superframeworks.beehiiv.com/p/21k-145k-mrr-in-4-months-solo-no-ads); $260,759 MRR, 7,622 subscriptions Oct 12 2026 — [TrustMRR](https://trustmrr.com/startup/postiz).
- Cap: 18k stars May 2026 → 23,221 Oct 2026; pricing $8.16-$12/user/mo Pro plus a $58 one-time desktop license — [ScreenSnap](https://www.screensnap.pro/blog/cap-so-review); [cap.so/pricing](https://cap.so/pricing).
- Better Auth: repo created 2024-05-19, 30,264 stars by 2026-10-12 — [GitHub](https://github.com/better-auth/better-auth); $5M seed June 24 2025 led by Peak XV; hosted product still on waitlist — [Better Auth blog](https://www.better-auth.com/blog/seed-round); "first known software tool from Africa to receive YC support" — [Dealroom](https://app.beta.dealroom.co/news/feed/better-auth-secures-500k-from-y-combinator).
- Polar: v1.0 Sept 2024; 5,300 stars at the 2025 seed announcement → 10,358 Oct 2026; developers on the platform "growing their revenue 120%+ month-over-month on average" (platform GMV, not Polar revenue) — [Polar seed](https://polar.sh/blog/polar-seed-announcement); [GitHub](https://github.com/polarsource/polar).
- OpenCut: created 2025-06-22, 93,660 stars by 2026-10-12, MIT, no cloud; ROSS 2025 #2 at 32.0x — [GitHub](https://github.com/OpenCut-app/OpenCut); [ROSS](https://runacap.com/ross-index/annual-2025/).
- Instatic ("open-source alternative to Webflow, Framer and WordPress"): created 2026-04-30, 8,924 stars in ~5 months, MIT — [GitHub](https://github.com/CoreBunch/Instatic).
- Zero (email client): created 2025-02-02, 10,846 stars, but last push 2026-05-26 (stalled) — [GitHub](https://github.com/Mail-0/Zero).
- Quackback (Canny alt, Dec 2025, 312 stars), FeedLog (Apr 2026, 174), Refferq (Oct 2025, 131), keygate (Mar 2026, 104): new entrants in the empty categories, none yet with traction — [GitHub API 2026-10-12](https://github.com/QuackbackIO/quackback).
- Macro trend: ROSS 2025 top-20 by star growth is dominated by AI agents/coding tools and most are VC-funded (Browser Use $17.5M, Firecrawl $17.6M, Coze $75M); "few are solo or bootstrapped" — [ROSS 2025](https://runacap.com/ross-index/annual-2025/).
- Pricing pattern across the 2025-26 cohort: Rybbit $13/$26, Postiz $29-$99, Cap $8.16-$12, Umami $0/$20/$200, OpenStatus $0/$30/$100, Documenso $0/$25/$40, Fider $0/$25, Twenty $9/$19 per user — all vendor pricing pages fetched 2026-10-12 (links above).

### Inferences
- The fast-growers pair an AGPL license (Rybbit, Postiz, Polar is Apache, Cap custom) with a flat, low, non-per-seat cloud price and a free self-host path. Per-seat pricing (Twenty, Cal.com, Unleash, GrowthBook) correlates with the VC-backed, team-oriented products rather than the indie ones.
- 2026-specific distribution channel: agent integrations (MCP server, CLI, agent skill registries). Postiz's founder attributes the $21k → $145k MRR jump in four months directly to this.
- Analytics shows the "crowded but still growing" dynamic: Rybbit reached 13k stars and ~$110k/yr run-rate in 18 months despite Plausible, Umami, Matomo and PostHog already existing, by combining a modern UI with session replay at $13.

- Cap, Documenso, Better Auth, Polar and Dub publish no revenue; Documenso promised open metrics in 2023 but none were found.
