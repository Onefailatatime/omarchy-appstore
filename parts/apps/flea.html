What is the flea file manager?

Flea is a GUI file manager built for Omarchy. It has four views, Quick Look previews on Space, undoable file operations, and vim, Mac or Windows style keys. To install it and make it your default file manager, run:

omarchy pkg add flea && flea --default

To try it without changing your defaults, run only omarchy pkg add flea.

What does flea do?

  • Four views. List, columns, grid and two panes, with tabs. Flea can remember the view for each folder.
  • Quick Look. Press Space to preview images, PDFs, text, media, archives and 3D model thumbnails.
  • File operations with undo. Copy, move, rename, trash, compress and extract, plus renaming many files at once.
  • Tags. Seven tags in your theme's colors. Press T, then 1 to 7, and search them with tag:red.
  • Network and devices. SMB, SFTP, FTPS, WebDAV, NFS, Dropbox and Taildrop, plus USB drives, encrypted drives, phones and cameras from the sidebar.
  • Disk images. Write an ISO or IMG to a USB drive and verify every byte.
  • The shelf. It sits in the Omarchy bar and holds files you send to it, so you can drag them into any app later.
  • Fits Omarchy. It follows your theme colors, text sizes and window transparency.

How do I make flea my default file manager?

  1. Run omarchy pkg add flea.
  2. To make it your default file manager, file chooser and the app on Super + Shift + F, run flea --default from a terminal in your session.
  3. To undo that, run flea --default off. The same switch is in Settings, then About.
  4. Updates come with omarchy update.

Want flea only for Open and Save dialogs? Run flea --picker. Moving from an AUR flea-bin or flea-git install? Run sudo pacman -S flea and answer y when pacman asks to replace it. Removing it: run flea --default off first, then omarchy pkg drop flea.

Prefer other keys? Settings has Default, Vim, Mac and Windows presets. The Windows preset uses Ctrl + Shift + 1 to 4 for views and Ctrl + Y for redo.

Flea or strata?

Both are GUI file managers you can install from the Omarchy repo, and you can try both.

Pick flea if you want the tightest fit with Omarchy's theme, bar and defaults. Pick strata if you like Miller columns and a GTK app. In the flea developer's own test on Oct 12, 2026, flea's window opened in 505 ms and strata's in 588 ms with 100,000 files in a folder (method).
