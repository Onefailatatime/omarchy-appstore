Maple Mono on Omarchy

Maple Mono is a free, open-source monospace coding font (OFL-1.1) with round corners, smart ligatures, and first-class Nerd Font icons — and this NF CN package adds full Chinese/Japanese glyphs, so one font covers your code, your terminal icons, and your CJK text.

TL;DR

omarchy pkg add maplemono-nf-cn

One command on Omarchy. It takes a few minutes (152 MB download). Version 7.9-1, listed on omarchyapps.com. Upstream: subframe7536/maple-font (29K+ stars). AUR package: maplemono-nf-cn.

Getting started (5 minutes)

1. Install and confirm it's registered.

After the install finishes, check that fontconfig picked it up:

fc-list | grep -i maple

You should see entries across several weights (Regular, Bold, Medium, etc.) plus italics. Write down the exact family name it reports. Everything below uses that exact name — don't guess it.

2. Set it as your ghostty font.

Omarchy ships ghostty as the terminal, and its config lives at ~/.config/ghostty/config. Add this line (one setting per line):

font-family = Maple Mono NF CN

Use the exact family name from fc-list in step 1 (the name above is the expected one — UNVERIFIED until the on-machine checklist is complete). Then reload the config instantly with ctrl+shift+, — no restart needed. You can validate the file first with ghostty +validate-config.

3. Test icons and ligatures.

Paste this in the terminal and hit enter:

printf '\uf07b \uf013\n'

You should see a folder icon and a gear icon. If you see tofu boxes instead, you're pointed at the wrong family name — go back to step 1. To see ligatures in action, type an operator like =>, !=, or == in your editor or shell. If ligatures don't render, enable them explicitly in ghostty:

font-feature = +liga
font-feature = +calt

Where config lives: fontconfig. The package installs system-wide (typically /usr/share/fonts on Arch). Per-user fonts go in ~/.local/share/fonts/, and per-user fontconfig rules live in ~/.config/fontconfig/fonts.conf. Refresh the cache after any manual font change with fc-cache -f -v.

Common issues & fixes

Nerd Font icons (Starship prompt, directory listings) show as empty boxes after switching

Fix: You're almost certainly using the plain "Maple Mono" family name instead of the Nerd Font one. Run fc-list | grep -i maple, find the entry whose family includes "NF", and paste that exact name into font-family in ~/.config/ghostty/config. Then reload with ctrl+shift+,. Apps also cache font lists at startup, so fully quit and reopen anything that still shows boxes.

Ligatures (=>, !=, ==) don't combine into single glyphs

Fix: Maple's smart ligatures are OpenType contextual alternates (calt). Enable them in ghostty with font-feature = +calt and font-feature = +liga. In editors, check the font ligatures toggle (VS Code: "editor.fontLigatures": true; Neovim GUI frontends have their own setting). This step is sourced from ghostty config docs and Maple's feature docs — UNVERIFIED on Omarchy until the checklist above is complete.

Chinese or Japanese text renders, but the spacing looks wider than other Chinese fonts

Fix: Expected behavior, not a bug. The CN variant is built on Resource Han Rounded and uses a strict 2:1 Chinese-to-English width ratio, which the README notes makes "spacing of Chinese characters larger compared to other popular Chinese fonts." If you hate it, switch to the non-CN maplemono-nf build and let a separate CJK font handle Chinese (configure the fallback in ghostty with a second font-family line, or via fontconfig).

The install is slow, or you notice the 335.3 MB installed size

Fix: That's the CN glyphs. A full CJK character set based on Resource Han Rounded is heavy — this is one of the largest font packages in the store. If you don't read Chinese or Japanese, install the non-CN NF variant instead (unverified whether omarchyapps.com lists maplemono-nf separately — check the site). One wrinkle: upstream's README marks the AUR builds as "Not Recommended" (preferring the ArchLinuxCN repo), but on Omarchy the supported path is omarchy pkg add regardless.

Text looks slightly blurry or off on your display compared to the screenshots

Fix: This package is the hinted build (autohint applied). Upstream ships an unhinted variant (maplemono-nf-cn-unhinted) for users who prefer it, and hinting preference varies by display and DPI. If you switch variants, clear the font cache (fc-cache -f -v) and fully restart your apps — fontconfig and terminals both cache rendered glyphs.

Maple Mono is free software — no paid tier to beat

There is no free-alternative pitch here because Maple Mono is itself free (SIL Open Font License 1.1) — no paid software to replace. What you get for $0: a monospace coding font with round corners, smart contextual ligatures, baked-in Nerd Font icons, and a full Chinese/Japanese glyph set in one install, instead of juggling a separate CJK fallback font.

How to switch your terminal font (~5 minutes)

  1. Install the new font: omarchy pkg add maplemono-nf-cn (152 MB download; 335 MB installed).
  2. Get the exact family name: fc-list | grep -i maple — copy the family name exactly as fontconfig reports it.
  3. Point ghostty at it: Add font-family = Maple Mono NF CN (your exact name) to ~/.config/ghostty/config, then reload with ctrl+shift+,.
  4. Verify icons and ligatures: printf '\uf07b \uf013\n' should show a folder and a gear; type => to see ligatures combine. Tofu boxes mean the wrong family name — go back to step 2.
  5. What doesn't transfer: Nothing — a font swap has no state. Your old font stays installed unless you remove it; point every other app at the new name if you want consistency.

Frequently asked questions

What do "NF" and "CN" mean?

NF = Nerd Font variant: thousands of patched-in icons (folder glyphs, git symbols, OS logos) for terminal prompts like Starship and status bars. CN = Chinese variant: full CJK glyphs built on Resource Han Rounded, with a strict 2:1 width ratio to the Latin glyphs so mixed-language code and Markdown tables line up. This package is both.

Is this the hinted or unhinted build?

Hinted. The package description on omarchyapps.com says "(hinted)", matching upstream's autohint builds. An unhinted variant (maplemono-nf-cn-unhinted) exists upstream for users who prefer it (unverified whether it's listed on omarchyapps.com).

How do I set it as my terminal font on Omarchy?

omarchy pkg add maplemono-nf-cn, then get the exact family name with fc-list | grep -i maple, add font-family = <that name> to ~/.config/ghostty/config, and reload with ctrl+shift+,.

Will my Starship prompt icons still work?

Yes. That's what the NF in the name is for — the Nerd Font patches are baked in, so prompt icons, eza --icons listings, and Waybar module icons all render from the same font.

Why is the download 152 MB when other fonts are a few megabytes?

The CN half of the package. A complete Simplified + Traditional Chinese + Japanese glyph set is enormous; this package weighs 335.3 MB installed. If you don't need CJK, use a non-CN build and save the disk.
