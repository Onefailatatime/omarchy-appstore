wechat-bin on Omarchy

wechat-bin is Tencent's official native Linux WeChat client (Qt-based "xWeChat") for Omarchy — chat, Moments, Mini Programs, and voice/video calls in one app, with QR-code login from your phone.

TL;DR

omarchy pkg add wechat-bin

Takes ~10 minutes (331.8 MB download / 790.1 MB installed).

Free proprietary app — no paid tier. Note the binary is big: it installs at 790 MB.

Getting started (5 minutes)

1. First launch = QR-code login.

Open WeChat from the launcher. What you see: a large QR code. You cannot log in with a username/password — open the WeChat app on your phone, tap the + in the top right, tap "Scan", scan the code, and confirm on the phone. That's the only login path for every desktop/web WeChat client. After that, your session persists between launches.

2. The three things everyone needs to know:

  • It's a real native client, not a web wrapper. The Qt-based official build supports Mini Programs, Moments, and voice/video calls per the ArchWiki — substantially more than WeChat Web (web.wechat.com), which only does messaging + file transfer. If someone tells you "just use the web version," the things you'd lose are calls, Moments, and Mini Programs.
  • Fix input method before you type a word. The ArchWiki states plainly: the XMODIFIERS environment variable is required for this package to use input method. On Omarchy with fcitx5, if Chinese input doesn't work, add to the app's launcher entry: 
    env GTK_IM_MODULE=fcitx QT_IM_MODULE=fcitx XMODIFIERS=@im=fcitx wechat-bin
    (A real user hit exactly this after switching to Wayland and fixed it with the env vars — duanluan's notes.)
  • Check scaling on HiDPI. The same user's notes record that WeChat "does not scale correctly" — the fix was QT_SCALE_FACTOR=1.5 in the launcher entry. Tune the number to your display.

3. Where its config lives.

User data lives under ~/.config/wechat or ~/.WeChat depending on build — verify the actual path during the on-machine pass before publishing. (Marked unverified.)

4. Omarchy-specific note.

The stock wechat-bin package is the unmodified official binary. A community AUR package named wechat wraps the same binary with sandboxing plus input-method, HiDPI, background-portal, and hybrid-GPU workarounds — that's an AUR-only alternative, not in the Omarchy store. Also relevant: wechat-xwayland exists as an AUR workaround that "launches wechat-bin through Qt XWayland with a KDE activation command" — it implies the Qt-native Wayland mode has tray/activation quirks on some setups; the specific failure mode is unverified, so test tray behavior on Omarchy directly.

Common issues & fixes

All items below are from the ArchWiki WeChat page, GitHub issue threads, or real user notes — none are invented. Unverified items are marked as such.

Can't input Chinese — keystrokes go nowhere in the chat box (especially after switching to Wayland).

This is the best-documented WeChat-on-Linux issue. Per the ArchWiki, the XMODIFIERS environment variable is required for input method support in this package.

Fix: Set GTK_IM_MODULE=fcitx, QT_IM_MODULE=fcitx, and XMODIFIERS=@im=fcitx (adjust for ibus) in the launcher entry or the environment you launch it from. (ArchWiki: WeChat, duanluan/linux-notes)

UI is tiny or blurry on a HiDPI display.

Real user report: WeChat "does not scale correctly."

Fix: Set QT_SCALE_FACTOR=1.5 (or your preferred factor) on the launch environment. The community wechat AUR variant ships HiDPI fixes out of the box if the raw package fights you. (duanluan/linux-notes)

Icon elements / UI parts don't display.

A real reported symptom in the wechat-universal-flatpak tracker (issue #73), where users hoped a v32 build would resolve "icon elements not displaying." This is version-dependent rendering flakiness, and it's unverified on the exact 4.1.13.26-1 Omarchy package.

Fix: If you hit blank icons, try a newer package version first. (web1n/wechat-universal-flatpak#73)

Minimize-to-tray / background behavior is wrong on Wayland/Hyprland.

Unverified failure mode — but the signal is real: AUR's wechat-xwayland package exists specifically to launch wechat-bin through Qt XWayland, and the ArchWiki notes "background portal" fixes in the sandbox variant.

Fix: If tray misbehaves on Omarchy, test the XWayland launch path during verification. (AUR: wechat-xwayland, ArchWiki: WeChat)

Considering the Windows client under Wine instead for feature parity.

Per the ArchWiki, the Wine route is worse: "all the Mini Program function of Wine-based WeChat are not available, and pictures larger than a certain size cannot be sent."

Fix: Stick with the native Linux client. (ArchWiki: WeChat)

Pairs well with / If you hate this, try

Pairs well with

  • fcitx5 (get input method right once and every Chinese app benefits)
  • Qt theming (Kvantum/Qt settings to match the Omarchy look)
  • the wechat-xwayland AUR workaround if the native Wayland tray path misbehaves

If you hate this, try

  • WeChat Web (web.wechat.com) — zero install, QR login, but messaging + file transfer only (no Moments, no calls)
  • the community wechat AUR variant (same official binary + sandboxing and input/HiDPI/GPU workarounds)
  • Windows WeChat under Wine (not recommended — loses Mini Programs and large image sends)

Frequently asked questions

Does wechat-bin work on Omarchy?

Yes — it's Tencent's official Qt-based Linux client, packaged for the Omarchy store. Install with omarchy pkg add wechat-bin. The package is large (790 MB installed).

Is wechat-bin free?

Yes. Proprietary freeware under Tencent's WeChat license (LicenseRef-WeChat). No paid tier.

How do I log in?

QR code only. Open the app, scan the code with the WeChat app on your phone, confirm on the phone. There is no username/password login for desktop WeChat.

Why can't I type Chinese in WeChat?

The known input-method gap: the ArchWiki says the XMODIFIERS environment variable is required for this package to use input method. Launch with GTK_IM_MODULE=fcitx QT_IM_MODULE=fcitx XMODIFIERS=@im=fcitx (adapt for ibus).

Does it support voice/video calls and Mini Programs?

Per the ArchWiki, the official Linux client supports Mini Programs, Moments, and VoIP — unlike the Wine-based Windows client, where Mini Programs don't work at all. (Verify on-machine during the checklist pass.)

How is this different from WeChat Web?

WeChat Web is messaging + file transfer only. The native client adds voice/video calls, Moments, and Mini Programs — at the cost of a 790 MB install.
