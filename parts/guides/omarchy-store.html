Looking for an Omarchy store?

Omarchy Apps lists __PKG_COUNT__ packages from the official Omarchy package repository, each with its own profile page. Whether you searched for omarchy store, omarchystore or omarchy app store, this is a catalog you can browse by category, search by name, and use to find the exact install command for any package.

The catalog is rebuilt from pkgs.omarchy.org twice a day, so new packages appear here shortly after they land in the repository. Omarchy Apps is an independent community project. It is not affiliated with or endorsed by Omacom or David Heinemeier Hansson.

How to browse the store

  1. Search the homepage. The Omarchy Apps homepage has a search box and a card for every package, grouped by category.
  2. Open a category. Each category page below lists every package of that kind on one page.
  3. See what readers like. The Top apps leaderboard ranks packages by reader votes.
  4. Scan the full list. The Omarchy apps list shows every package in the repository on a single page.
  5. Read a guide. The guides cover setup, comparisons and app by app walkthroughs.

Every app profile shows the package version, license, project homepage, source and requirements, so you can check what you are installing before you run anything.

How to install an app from the store

Open the app's profile, confirm it is the project you expect, then copy the command it shows into a terminal:

omarchy pkg add <package-name>

Use the exact package name from the profile. To remove a package later, run omarchy pkg drop <package-name>. This website does not host or download any software. The command hands the install to Omarchy and its configured package sources, and the package then updates with the rest of your system.

For apps that are not in the Omarchy repository yet, the guide on how to install apps on Omarchy safely covers Arch packages, the AUR and a quick safety check.

Frequently asked questions

What is the Omarchy store?

Omarchy Apps is an unofficial store and catalog of apps for Omarchy. It lists every package in the official Omarchy package repository, with a profile page for each one showing its source, license, requirements and install command.

How do I install an app from the Omarchy store?

Open the app's profile, check the project link and requirements, then run omarchy pkg add followed by the exact package name in a terminal. The install runs through Omarchy and its package sources. This site does not host or download packages.

Is Omarchy Apps the official Omarchy store?

No. It is an independent community project, not affiliated with or endorsed by Omacom or David Heinemeier Hansson. The packages it lists come from the official repository at pkgs.omarchy.org.

How often is the catalog updated?

The catalog is rebuilt from pkgs.omarchy.org twice a day, so new packages show up shortly after they land in the official repository.

Can I suggest an app that is missing?

Yes. You can suggest an app from the homepage, and the Develop page explains how packaging for the official Omarchy repository works.
