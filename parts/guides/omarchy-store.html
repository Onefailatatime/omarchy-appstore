What this store is

Omarchy Apps is an unofficial, browsable store front for the official Omarchy package repository. It lists all __PKG_COUNT__ packages published at pkgs.omarchy.org, gives each one a profile page, and shows the exact command to install it. Nothing here is a separate catalog: if a package is on this site, it is in the official repo, and when it leaves the repo it leaves this site too.

The site does not host, mirror or download any software. Installs run on your own machine through Omarchy and its configured package sources. Omarchy Apps is an independent community project, not affiliated with or endorsed by Omacom or David Heinemeier Hansson. It is also not omarchystore.com, which is a different site.

Which "Omarchy store" do you mean?

The phrase gets used for three different things. They are easy to mix up, so here is the short version.

How to browse the store

  1. Search the catalog. The Omarchy Apps homepage has a card for every package, grouped by category. Press / to jump to the search box and type part of a name or what the app does.
  2. Open a category. Each category page lists every package of that kind on one page, with a one line summary.
  3. See what other readers use. The Top apps leaderboard ranks packages by reader upvotes.
  4. Read a guide when you are choosing. The guides cover first installs, comparisons and app by app walkthroughs.

How to install an app from the store

Every profile shows one command. Copy it into a terminal on Omarchy:

omarchy pkg add <package-name>

You can list several names on one line, for example omarchy pkg add flea strata rustdesk. If you would rather not type, open the Omarchy menu with Super + Space, choose Install, then Package, and type the same name. Press Tab to mark several packages and Enter to install them together.

To remove a package later, run omarchy pkg drop <package-name>. Installed packages update with the rest of the system when you run omarchy update or choose Update, then Omarchy, in the menu. The full walkthrough, including the AUR and a short safety check, is in how to install apps on Omarchy.

What to check before you install

A profile page is there so you can see what you are about to run before you run it. On each one, look at:

  • The exact package name. Names ending in -bin usually install a prebuilt release from the upstream project; other variants may build from source or follow a nightly channel.
  • Source and project links. Each profile links the upstream project and the package's PKGBUILD in omarchy-pkgs, so you can confirm it is the project you expect.
  • Version, license and size. These come straight from the repository database and refresh twice a day.
  • Requirements. Some packages only make sense on specific hardware, such as kernel and firmware packages for one laptop model.

Frequently asked questions

Is this the official Omarchy store?

No. Omarchy Apps is an independent community project, not affiliated with or endorsed by Omacom or David Heinemeier Hansson. It lists the packages from the official repository at pkgs.omarchy.org. Omarchy's own way to install software is the Install menu and the omarchy pkg add command.

Is this omarchystore.com?

No. omarchystore.com is a separate site run by other people, with its own desktop app and catalog. Omarchy Apps lives at omarchyapps.com only. Here is how the two compare.

How do I install an app from this store?

Open the app's profile, check the project link and requirements, then run omarchy pkg add followed by the exact package name in a terminal. The install runs through Omarchy and its package sources. This site does not host or download packages.

How often is the catalog updated?

It is rebuilt from pkgs.omarchy.org twice a day, so new packages show up shortly after they land in the official repository.

Why is an app I use missing?

Only packages in the official Omarchy repository are listed. Many other apps install from Arch or the AUR instead; the install guide shows how. Developers can read Develop for Omarchy to get a package into the official repo.
