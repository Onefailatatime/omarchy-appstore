Two things to know first

  • Omarchy becomes the only OS on that drive. The Mac support page says the drive is wiped and macOS will not boot afterward. You can restore macOS later through Internet Recovery.
  • Intel only. Omarchy has built-in support for Intel Macs. M-series Macs are not directly supported. Not sure which you have? See which Macs can run Omarchy.

Step by step

1. Back up

Copy your files to an external drive or make a Time Machine backup. The safe Mac migration guide has a checklist.

2. Write the USB

Download the ISO from omarchy.org (the page links a SHA-256 checksum and signature so you can verify it) and write it to a USB stick with balenaEtcher.

3. Turn off Secure Boot

  1. Turn off the Mac.
  2. Turn it on and hold Command + R until the loading screen.
  3. Pick your user and enter your password if asked.
  4. From the menu bar choose Utilities > Startup Security Utility.
  5. Choose No Security under Secure Boot.
  6. Choose Allow booting from external or removable media under External Boot.

4. Boot from the USB

Insert the stick, restart, and hold Option until you see boot devices. Select the orange EFI Boot device.

5. Install

Answer the setup questions and pick the drive. The installer detects Mac hardware and applies fixes automatically: Broadcom Wi-Fi drivers and firmware, the SPI keyboard driver on the MacBooks that need it, and an NVMe suspend fix for those models. Getting Started says the whole install should not take more than 5 minutes, even on an older computer.

Your first ten minutes

On a Mac keyboard, the Command key works as Super, so Command + Space opens the Omarchy menu. Install a first app with one line, for example LocalSend to pull files from your phone:

omarchy pkg add localsend

Frequently asked questions

Can I install Omarchy on an Intel Mac?

Yes. Omarchy has built-in support for Intel Macs. The installer applies the Wi-Fi, keyboard and suspend fixes those Macs need.

Will installing Omarchy erase macOS?

Yes. Omarchy currently has to be the only OS on the Mac's drive, so it is wiped. You can restore macOS later through Internet Recovery.

How do I boot an Intel Mac from USB?

Restart and hold Option until the boot devices appear, then select the orange EFI Boot device. You may need to allow external boot in Startup Security Utility first.

How long does the install take?

The Getting Started guide says it should not take more than 5 minutes even on an older computer.

Does the Command key still work?

Yes. Linux treats the Command key as Super, so it sits where Cmd always was.
