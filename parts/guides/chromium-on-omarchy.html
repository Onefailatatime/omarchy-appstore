Chromium on Omarchy

Chromium on Omarchy is the open-source browser behind Google Chrome: fast, standards-compliant, and free of Google account tracking, but without Chrome’s proprietary codecs and DRM module.

TL;DR

omarchy pkg add chromium

That installs Chromium (181.7 MB download, 435.3 MB installed, BSD-3-Clause). It launches like any other browser (chromium). Know this before you switch: Netflix, Spotify, and some video sites will not play until you add Widevine DRM, and some H.264 video will not play at all. The store page lists no version number — confirm the installed version with chromium --version.

Getting started (5 minutes)

1. Launch it and set it as default.

Open the Omarchy menu (Super + Space), type chromium, and press Enter. On first launch it asks whether to make Chromium the default browser. Say yes if you want links from other apps to open here. There is no Google sign-in: Chromium ships without Google’s proprietary code, so there is no account sync. Your bookmarks, passwords, and history stay local unless you use a third-party sync extension.

2. Import your old browser data.

Go to chrome://settings/importData and pick your previous browser (Chrome, Firefox, or another Chromium browser). Import bookmarks, passwords, and history in one pass. If you are coming from Google Chrome, this is the step that makes the switch painless.

3. Three things worth doing in the first session:

  • Check how it is running on Wayland — open chrome://gpu and look at the window protocol. If it says XWayland and text looks blurry, quit and relaunch with chromium --ozone-platform-hint=auto, or set the “Preferred Ozone platform” flag to Auto at chrome://flags.
  • Install an ad blocker — Chromium uses the Chrome Web Store, so uBlock Origin installs the same way it does in Chrome. Open the Web Store, search for it, and click Add.
  • Know where your profile lives — bookmarks, extensions, and settings sit under ~/.config/chromium. Back that folder up if you want to carry your browser to another machine.

Common issues & fixes

Netflix, Spotify, Amazon Prime, or another streaming site shows an error and refuses to play video

Chromium ships without Widevine, Google’s proprietary DRM module, so DRM-protected video cannot play. This is expected, not a bug.

Fix: Install Widevine from the AUR with yay -S chromium-widevine, then restart Chromium and try again. If you would rather not touch the AUR, use Google Chrome or Firefox for streaming instead. (Arch install guide)

Some videos play with no sound, or will not play at all, while others work fine

Chromium on Arch ships without proprietary codecs (H.264, AAC, HEVC) because of patent licensing, so video encoded in those formats fails.

Fix: The Flatpak build of Chromium bundles a codecs extension that covers H.264, MP3, and AAC. If you installed from the Omarchy package and need those formats, install the Flatpak instead, or use Firefox, which handles them natively. (FossLinux install guide)

Chromium looks blurry on HiDPI, or window dragging and scaling feel wrong on Hyprland

It is probably running through XWayland instead of native Wayland.

Fix: Launch with chromium --ozone-platform-hint=auto and check chrome://gpu again. If that fixes it, make the flag permanent by setting “Preferred Ozone platform” to Auto at chrome://flags. (Arch Linux Forums)

Video playback uses the CPU heavily and the laptop fan spins up on YouTube

Hardware video decoding is not on by default.

Fix: First install the right VA-API driver for your GPU (intel-media-driver for Intel, mesa for AMD, libva-nvidia-driver for Nvidia). Then launch Chromium with --enable-features=VaapiVideoDecodeLinuxGL --ozone-platform=wayland and check chrome://gpu for “Video Decode: Hardware accelerated”. One gotcha from the Arch forums: if the flags seem to do nothing, delete the old profile cache (~/.config/chromium and ~/.cache/chromium) and try again, because stale config can block the new settings. (Arch Linux Forums)

Chromium is a free alternative to Google Chrome ($0, but your data is the product)

Chromium is a free alternative to Google Chrome ($0, but your data is the product). What you give up: Google account sync, built-in Widevine DRM, and proprietary codecs, so some video and streaming needs extra setup. What you keep: the same Blink engine, the same Chrome Web Store extensions, the same speed, and a browser you can inspect and build yourself. Chromium costs nothing and Google Chrome costs nothing too, so the trade is not money, it is control.

How to switch from Google Chrome (~10 minutes)

  1. Export from Chrome: export bookmarks from the Bookmark Manager (Ctrl + Shift + O, then the three-dot menu, Export bookmarks) as an HTML file. Passwords export from chrome://settings/passwords under the three-dot menu, as a CSV file. Treat that CSV as sensitive and delete it after importing.
  2. Import into Chromium: in Chromium, open chrome://settings/importData, choose Google Chrome, and import bookmarks, passwords, and history directly. Or import the HTML bookmarks file from the Bookmark Manager.
  3. What doesn’t transfer: your Google account sync (there is none in Chromium), Chrome’s saved payment methods tied to your Google account, and Widevine DRM, which needs the AUR package. Extensions transfer: reinstall them from the Chrome Web Store.
  4. Time estimate: takes about 10 minutes, plus a few more if you add Widevine.

Frequently asked questions

Is Chromium free?

Yes. It is open source under the BSD-3-Clause license, and the Omarchy package costs nothing.

What is the difference between Chromium and Google Chrome?

Chromium is the open-source project Chrome is built on. Chrome adds Google’s proprietary code: account sync, the built-in PDF viewer, Widevine DRM, and proprietary media codecs. Chromium leaves those out.

Can I use Chrome extensions in Chromium?

Yes. Chromium uses the Chrome Web Store, and extensions install the same way.

Why won’t Netflix play in Chromium?

Chromium has no Widevine DRM module. Install chromium-widevine from the AUR, or watch in Firefox or Chrome.

Where does Chromium store my profile?

Under ~/.config/chromium. Each profile is a subfolder there.

Does Chromium run natively on Wayland?

Usually yes with the Ozone hint set to auto, but confirm on your machine with chrome://gpu. If it shows XWayland, launch with --ozone-platform-hint=auto.
