Claude Desktop on Omarchy: Anthropic’s official Linux app, repackaged for Arch

Claude Desktop on Omarchy is Anthropic’s official Linux app (beta), repackaged for Arch — full chat, Projects, MCP connectors, Claude Code, and the Cowork agent mode, all from your desktop instead of a browser tab.

TL;DR install

omarchy pkg add claude-desktop

That pulls Omarchy’s claude-desktop package (~179 MB download, ~605 MB installed), which repackages Anthropic’s official Linux .deb verbatim. It’s the real app — not a web wrapper. But remember: the app binary is Anthropic’s, the Arch package is community-built and unsupported by Anthropic. Free to install; you need a Claude account (free tier works).

Getting started in 5 minutes

1. Launch and sign in

Find “Claude” in the Omarchy launcher (app icon is com.anthropic.Claude). First launch opens a browser-based sign-in: log in with your Claude account and the claude:// redirect hands the token back to the app. If the redirect stalls on Hyprland, see Issue #1 below.

2. Start a new chat

The chat interface is identical to claude.ai — same models, same context windows (up to 1M tokens on paid plans). Pick a model, type, go.

3. Three things worth doing in the first session

  • Connect a folder (MCP). Claude Desktop’s signature feature over the browser is MCP servers — local file access, databases, and tools Claude can actually use. Config lives at ~/.config/Claude/claude_desktop_config.json (quit the app before hand-editing it; the app overwrites edits made while running).
  • Open the Claude Code tab. This build ships with Claude Code integration — use the system-installed Claude Code CLI from inside the app, with changes shown as diffs you approve.
  • Try a Cowork task. Cowork is the autonomous agent mode: it can work on your files, organize folders, and create documents without you approving each step. First use downloads a ~1.3 GB VM image that expands to roughly 12 GB under ~/.config/Claude/vm_bundles/, and it runs Cowork inside a KVM virtual machine (x86_64 only).

Common issues & fixes

Login doesn’t stick on Hyprland, or credentials are stored insecurely

Fix: This is upstream Chromium behavior on desktops it doesn’t recognize (Hyprland, Sway) — not a packaging bug. Workaround: copy the .desktop file to ~/.local/share/applications/, add --password-store=kwallet6 (or --password-store=gnome-libsecret) to its Exec= lines, then run update-desktop-database ~/.local/share/applications. (AUR claude-desktop maintainer notes)

The Cowork tab fails to start or the VM won’t boot

Fix: Cowork needs KVM access and its VM stack. Check your user can reach /dev/kvm (some setups need you added to the kvm group). Install the optional dependencies the package declares: qemu-system-x86, edk2-ovmf, and virtiofsd — Omarchy’s PKGBUILD already maps the app’s Debian-hardcoded VM paths onto Arch locations via symlinks, so you only need the packages themselves. Cowork is x86_64-only; there’s no UEFI firmware package on Arch Linux ARM. (AUR maintainer notes; omarchy-pkgs PKGBUILD)

The app never auto-updates itself

Fix: Expected on Linux — the app has no self-updater here. New versions arrive through system package updates. On Omarchy, omarchy update picks up new builds (Omarchy’s package tracks Anthropic’s Debian repo, which ships frequent releases). (itbrief.co.nz)

MCP servers you added by editing claude_desktop_config.json disappear

Fix: Quit Claude Desktop before hand-editing ~/.config/Claude/claude_desktop_config.json, then relaunch. The app rewrites its own config while running, so edits made against a live app get overwritten on the next write. (claude-desktop-debian README)

Features you saw on a Mac/Windows demo — Computer Use, dictation — are missing

Fix: Not a bug: the Linux beta doesn’t have Computer Use or dictation, and the Ctrl+Alt+Space Quick Entry shortcut needs extra portal help on Wayland. Chat, Projects, Claude Code, MCP, and Cowork all work. (ubuntufree.com Linux FAQ)

Pairs well with / If you hate this, try

Pairs well with

  • Claude Code (terminal agent — same subscription, already integrated into Omarchy 4.0’s AI menu), a secrets manager or gnome-keyring for the login issue above, and qemu/virtiofsd if you plan to use Cowork.

If you hate this, try

  • Just use claude.ai in the browser — same models, zero install, and the only things you lose are MCP local-file access and Cowork. Heavy terminal users often prefer Claude Code alone.

The software is free, the intelligence is freemium

The app itself costs nothing — it’s free to install and free to run on a free Claude account. What you can do inside it follows your plan: Free ($0) covers chat on web, desktop, and mobile; Pro ($20/month, or $200/year) adds at least 5× usage per session, the biggest context windows, Claude Code, and (on higher tiers) Cowork. So the honest pitch: the software is free, the intelligence is freemium — and a free account is enough to decide whether the desktop extras (MCP, Cowork) are worth paying for.

Frequently asked questions

Is there an official Claude desktop app for Linux?

Yes — since June 30, 2026, Anthropic ships a first-party Linux beta as a .deb (amd64 + arm64) from its own signed APT repository at downloads.claude.ai. It’s a beta and it doesn’t auto-update itself, but it’s Anthropic’s code, not a third-party port.

Is claude-desktop on Omarchy official?

Half and half. The app binary is Anthropic’s official Linux build, downloaded from Anthropic’s own repository. But Anthropic doesn’t ship an Arch package — the one omarchy pkg add installs is maintained by the Omarchy community in omarchy-pkgs, and Anthropic won’t support issues with it. Report packaging problems to Omarchy, not Anthropic.

Is it free?

The app is free to install and free to use with a free Claude account (no signed-out mode — you need an account). Capability limits follow your Claude plan: Free, Pro ($20/mo), Max, etc.

Does it work offline or run a model locally?

No to both. Every message goes to Anthropic’s servers. The virtual machine Cowork uses is a sandbox around what Claude can touch — it’s not a local model.

Where do MCP settings live?

~/.config/Claude/claude_desktop_config.json. Quit the app before editing it by hand.
