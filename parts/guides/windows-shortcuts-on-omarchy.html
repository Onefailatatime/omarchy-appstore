Three keys that behave differently

  • Ctrl + Alt + Del closes all windows on Omarchy. It is not a task manager. Save first.
  • Caps Lock is a compose key for quick emoji and symbols. If you want Caps Lock back, set kb_options = "compose:ralt" in ~/.config/hypr/input.lua (Setup, then Input, in the menu).
  • Quick panels live on Super + Ctrl + A (audio), B (Bluetooth) and W (Wi-Fi).

How to learn the rest in two weeks

The Omarchy manual's advice for switchers is to give it two weeks. Skim the hotkeys once, and whenever you blank, press Super + K to see every binding. If the Windows key is awkward on your keyboard, the manual shows how to swap Alt and Super with altwin:swap_alt_win.

Frequently asked questions

What is the Super key on Omarchy?

It is the Windows key on a PC keyboard, and the Command key on a Mac. Nearly every Omarchy hotkey starts with it.

What replaces the Windows Start menu?

Super+Space opens the Omarchy menu, which launches apps, opens settings and installs software. Start typing to filter.

How do I take a screenshot like Win+Shift+S?

Press Print Screen. Omasnap opens so you can select an area and add arrows, text or blur.

Where is clipboard history like Win+V?

Super+Ctrl+V. It holds images as well as text.

How do I see all the keyboard shortcuts?

Press Super+K. It lists every binding Omarchy has set up.

What does Ctrl+Alt+Del do on Omarchy?

It closes all windows. Use Super+Escape for the power menu instead.
