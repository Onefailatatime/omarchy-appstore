What are the best apps to install first on Omarchy?

A fresh Omarchy install already has a lot of the best apps. LocalSend, Aether, Omacut, Obsidian, LibreOffice, Pinta, Omawrite, Chromium and Hype are all part of Omarchy's base package list. So the best first move is to add what's missing. Start with a file manager, notes and remote access:

omarchy pkg add strata slap-notes-bin rustdesk

Or open the Omarchy menu (Super + Space), choose Install, then Package, press Tab on each one and press Enter. Add the specialist tools below only when a job calls for them.

Disclosure: Slap Notes is made by Jessyka, who runs this site.

What apps come preinstalled on Omarchy?

These come with Omarchy, so there's nothing to install. The source is Omarchy's base package list (install/omarchy-base.packages in the Omarchy source), and the GUIs and TUIs chapters of the manual describe them:

  • LocalSend for sending files between devices
  • Aether for building a theme from a wallpaper
  • Omacut for quick video trims
  • Obsidian for Markdown notes
  • LibreOffice for documents and spreadsheets
  • Pinta for simple image edits
  • Omawrite for writing
  • Chromium as the browser
  • Hype, Monologue, Omacalc, Signed and Disktree, which are Omarchy's own small tools

Editors like VSCode, Cursor and Zed are under Install, then Editor, and Steam and Heroic are under Install, then Gaming (Development Tools, Gaming).

Five useful apps for almost any Omarchy setup

1. LocalSend: private file transfers between your devices

Already installed. Send files between Linux, Windows, macOS, Android and iOS on the local network without uploading them to a cloud drive. It is the practical cross platform answer to “how do I AirDrop this to Linux?”

2. Slap Notes: local blocks and linked notes

omarchy pkg add slap-notes-bin

A native notes workspace with block editing, wiki links, a visual graph, daily notes and an optional research agent. It is particularly interesting if Notion feels too cloud first and plain Markdown feels too bare.

3. Strata: keyboard first file management

omarchy pkg add strata

Browse with Miller columns, thumbnails or a sortable table, then use fuzzy search and previews to move through files quickly. Its GTK4 interface fits naturally beside the rest of an Omarchy desktop.

Prefer Flea? It's the other keyboard first file manager in the repo: Flea on Omarchy.

4. Aether: build a theme from a wallpaper

Already installed. Extract a palette from an image, tune it and generate a coordinated theme across the desktop and supported apps. It turns Omarchy customization into a visual workflow instead of a manual color file exercise.

5. RustDesk: remote desktop access

omarchy pkg add rustdesk

A useful option when you need to reach another computer or help someone remotely. Review the networking and security model before exposing any remote access tool.

Four creative and presentation tools

6. Omacut: trim a clip without a full editor

Already installed. Open a video, choose the start and end, preview and export. It is intentionally much smaller than a multitrack editor.

7. Omapresent: turn Markdown into slides

omarchy pkg add omapresent

Present directly from structured Markdown, keep speaker notes on a separate display and export to PDF or a static web bundle.

8. Schist: a layered image editor

omarchy pkg add schist-bin

Built for serious layer based image work with PSD and Affinity compatibility goals, non destructive editing and an extensible plugin design.

9. Hyprshade: screen shaders for Hyprland

omarchy pkg add hyprshade

Apply and manage screen shaders for effects such as blue light reduction or visual customization without rebuilding the desktop.

Three picks for developers and gamers

10. Codex CLI: a coding agent in the terminal

omarchy pkg add openai-codex-bin

Work with a coding agent inside a repository: ask questions, review changes, edit files and run project commands. It requires an eligible OpenAI account or API access.

11. Cursor: an AI first code editor

omarchy pkg add cursor-bin

A familiar VS Code style environment with integrated agents for people who prefer a desktop IDE over a terminal first coding workflow.

12. Heroic Games Launcher: one library for several game stores

omarchy pkg add heroic-games-launcher-bin

Manage Epic, GOG and Amazon game libraries, plus Wine and Proton compatibility tools, from an open source launcher built for Linux as well as macOS and Windows.

Frequently asked questions

What are the best apps to install on Omarchy first?

LocalSend, Aether and Omacut already come with Omarchy. Add Strata for files, Slap Notes for linked notes and RustDesk for remote access with omarchy pkg add strata slap-notes-bin rustdesk.

What apps come preinstalled on Omarchy?

LocalSend, Aether, Omacut, Obsidian, LibreOffice, Pinta, Omawrite, Chromium and Hype, plus Omarchy's own small tools like Monologue and Disktree. Neovim is the default editor.

Is there an Omarchy app store?

The built in one is the Omarchy menu: Install, then Package or AUR. This site is an unofficial directory on top of it, with a profile and an install command for every app in the Omarchy repo.

How do I install several of these at once?

Put all the package names after omarchy pkg add, separated by spaces. Or open Install, then Package in the Omarchy menu, press Tab on each one, then Enter.

What's the best file manager for Omarchy?

Strata and Flea are both keyboard first and both in the repo. Strata has Miller columns, thumbnails and a table view. Flea focuses on speed, rich previews of images, video, PDFs and archives, and undoable file operations. See Flea on Omarchy and the Strata FAQ.

Are these official Omarchy apps?

Some are Omarchy projects and some are third party or indie apps packaged in the Omarchy Package Repository. Each profile links to the real upstream project.

Does this page install anything?

No. It links to profiles and shows commands. You run them yourself.

How to verify a pick

Every linked profile displays the current package version, license, size, upstream website or repository, PKGBUILD and known requirements. Treat those pages as a starting point and read the upstream documentation before granting an app access to important data.
