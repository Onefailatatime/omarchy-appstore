Firefox on Omarchy

Firefox on Omarchy is Mozilla’s fast, private, and safe web browser: the independent Gecko engine, real privacy controls, and DRM video that works with no extra packages.

TL;DR

omarchy pkg add firefox

That installs Firefox (125.9 MB download, 345.6 MB installed, MPL-2.0). Launch it with firefox. It is the browser that needs the least setup on Omarchy: streaming works, extensions work, and it runs natively on Wayland. The store page lists no version number — confirm the installed version with firefox --version.

Getting started (5 minutes)

1. Launch it and import your old browser.

Open the Omarchy menu (Super + Space), type firefox, and press Enter. On first launch Firefox offers to import bookmarks, passwords, and history from Chrome or Chromium. Take it: the import wizard does the whole move in one pass. Then accept the default-browser prompt if you want links from other apps to open here.

2. Set up sync if you want it, skip it if you don’t.

Firefox Sync (a free Mozilla account) carries bookmarks, passwords, and open tabs between machines. Unlike Chrome, sync is optional and the browser works fully without it. Turn it on from the menu under Settings, Sync, or ignore it and keep everything local.

3. Three things worth doing in the first session:

  • Check Wayland and hardware video — open about:support and look under Graphics. Window Protocol should say wayland, and Hardware Video Decoding should say available. If video decoding is not available, see the VA-API fix below.
  • Install uBlock Origin — open about:addons, search for uBlock Origin, and install it. It is the single highest-value extension for any browser.
  • Know where your profile lives — bookmarks, extensions, and settings sit under ~/.mozilla/firefox, in a folder ending in .default-release. Back that folder up if you want to carry your browser to another machine.

Common issues & fixes

Firefox shows “Firefox is already running, but is not responding” and will not start

A leftover lock file is the usual cause: Firefox crashed or was killed and never cleaned up.

Fix: First check no Firefox process is actually running with ps aux | grep firefox and kill any strays. Then open your profile folder under ~/.mozilla/firefox/ and delete the lock and .parentlock files inside the profile folder. Do not delete the whole profile folder: that wipes bookmarks and settings. (Mozilla Support)

Video playback uses the CPU heavily and the laptop fan spins up on YouTube

Hardware video decoding is off until you turn it on.

Fix: First install the right VA-API driver for your GPU: intel-media-driver for Intel (Broadwell and newer), mesa for AMD, libva-nvidia-driver for Nvidia. Then open about:config, accept the warning, and set media.ffmpeg.vaapi.enabled to true. Restart Firefox and check about:support: Hardware Video Decoding should now say available. (Firefox Wayland guide)

Firefox looks blurry or scales wrong on a HiDPI screen, or behaves like an X11 app

It is running through XWayland instead of native Wayland. Firefox 115 and later auto-detects a Wayland session, so this mostly affects older setups or odd launches, but check about:support for the window protocol.

Fix: If it says xwayland, launch with MOZ_ENABLE_WAYLAND=1 firefox. To make it permanent, add MOZ_ENABLE_WAYLAND=1 to your environment or edit the desktop file’s Exec line to Exec=env MOZ_ENABLE_WAYLAND=1 /usr/lib/firefox/firefox %u. (Firefox Wayland guide)

After forcing hardware decoding on, the logs fill with “Failed to create ~/.cache/mesa_shader_cache for shader cache (Permission denied)” errors

This is a known issue reported on the Arch forums when media.ffmpeg.vaapi.enabled and media.hardware-video-decoding.force-enabled are both forced on, and it appears tied to the sandbox rather than the driver: vainfo reports everything fine while the errors repeat.

Fix: Leave media.hardware-video-decoding.force-enabled at its default (off) and only enable media.ffmpeg.vaapi.enabled, which gives hardware decoding without the error spam on most setups. If the errors persist, check the permissions on ~/.cache/mesa_shader_cache before forcing anything else. (Arch Linux Forums)

Firefox is a free alternative to Google Chrome ($0, but your data is the product)

Firefox is a free alternative to Google Chrome ($0, but your data is the product). What you give up: Google account sync across Chrome, and a few Chrome-only extensions. What you keep: a fast modern browser, DRM video that plays with no extra packages, and a non-profit steward (Mozilla) instead of an ad company. Firefox costs nothing and Chrome costs nothing too, so the trade is not money, it is who holds your data.

How to switch from Google Chrome (~5 minutes)

  1. Export from Chrome: you do not need to export anything by hand. Firefox’s import wizard reads Chrome directly.
  2. Import into Firefox: on first launch, or later from the menu under Bookmarks, Manage bookmarks, Import and Backup, Import Data from Another Browser, choose Chrome. It pulls bookmarks, passwords, history, and open tabs in one pass.
  3. What doesn’t transfer: Chrome extensions (find Firefox equivalents on addons.mozilla.org; uBlock Origin and Bitwarden are both there), Google account sync, and saved payment methods tied to your Google account.
  4. Time estimate: takes about 5 minutes, plus a few more to reinstall your extensions.

Frequently asked questions

Is Firefox free?

Yes. It is open source under the MPL-2.0 license, and the Omarchy package costs nothing.

Does Netflix work in Firefox on Linux?

Yes. Firefox ships Widevine DRM support, so Netflix, Spotify, and Prime play with no extra packages. Chromium, by contrast, needs Widevine installed from the AUR.

Does Firefox run natively on Wayland?

Yes, Firefox 115 and later auto-detects a Wayland session. Check about:support: Window Protocol should say wayland. If it says xwayland, launch with MOZ_ENABLE_WAYLAND=1 firefox.

Where does Firefox store my profile?

Under ~/.mozilla/firefox, in a folder ending in .default-release. profiles.ini in the same directory lists your profiles.

How do I enable hardware video decoding?

Install the VA-API driver for your GPU, then set media.ffmpeg.vaapi.enabled to true in about:config and restart. Verify in about:support.

Can I use Chrome extensions in Firefox?

No, not directly. Firefox uses its own add-ons site, addons.mozilla.org, but most popular extensions (uBlock Origin, Bitwarden, Dark Reader) have Firefox versions.
