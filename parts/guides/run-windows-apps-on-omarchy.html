Before you set up a VM

Check if you need Windows at all. Many apps have a web version, and Omarchy can turn any site into an app window with Install, then Web App. Microsoft says PowerPoint for the web is free, and Omarchy already ships Zoom and WhatsApp as web apps. For desktop Office files, LibreOffice comes preinstalled. If you still have a Windows PC, you can also just remote into it with RustDesk.

Set up the Windows VM

  1. Press Super + Space and choose Install, then Windows. Your machine needs KVM virtualization. If it is off in the BIOS, the installer tells you.
  2. Pick RAM, CPU cores and disk. Plan for the disk you give Windows plus about 10GB for the image. The manual calls 64GB the sensible floor.
  3. Set a Windows username and password, or leave them blank for docker / admin.
  4. Wait. The download takes 10 to 15 minutes. You can watch at http://127.0.0.1:8006.
  5. Open Windows from the app launcher. Give it 15 to 30 seconds on a cold start.
omarchy windows vm status   # is it running?
omarchy windows vm stop     # shut it down
omarchy windows vm launch   # start and connect

Closing the RDP window shuts the VM down. To leave it running, launch with omarchy windows vm launch --keep-alive.

Moving files in and out

The ~/Windows folder in your home is shared with the VM. Windows cannot see any other part of your files. The VM's ports listen on localhost only, so nothing on your network can reach it.

Licensing and limits

  • It installs Windows 11 Pro, unactivated. You need your own license key for the gated features.
  • omarchy windows key prints the OEM key from your PC's firmware. The manual says that key is bound to the machine and usually will not activate the VM.
  • No GPU passthrough, so not for gaming or video editing. For games, see gaming after Windows.
  • Remove > Windows deletes the VM and its disk. Copy anything you need out of ~/Windows first.

Frequently asked questions

Can I run Microsoft Office on Omarchy?

Yes, inside the Windows 11 VM from Install > Windows. The manual calls it a great way to run Office. For many files, LibreOffice or the free web versions are enough.

Does the Windows VM need a license?

It installs Windows 11 Pro unactivated. You need your own key for the gated features. Your PC's OEM key usually will not activate the VM.

Can I play games in the Windows VM?

No. There is no GPU passthrough. Use Steam with Proton, cloud gaming or Moonlight streaming instead.

How do I share files with the Windows VM?

Put them in ~/Windows in your home folder. That is the only folder Windows can see.

How much disk does the Windows VM need?

The disk you allocate plus about 10GB for the image. The manual suggests 64GB or more for the VM disk.
