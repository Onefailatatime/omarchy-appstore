Antigravity on Omarchy

Google Antigravity 2.0 is an agent-first development platform in a desktop app: instead of an AI assistant bolted onto an editor, you supervise several AI agents working in parallel across your projects while they plan, write, run, and verify code — and show you receipts for it. It’s for developers who want to direct outcomes (“rebuild this feature, prove it works”) rather than type every keystroke.

TL;DR

omarchy pkg add antigravity

Takes ~2 minutes plus a 208.4 MB download (542 MB installed). You will need a Google account to sign in — the agents run on Google’s Gemini models, and the free individual tier is usage-limited. Paid Google AI Pro and Ultra plans raise the limits and unlock extra models.

Getting started (5 minutes)

1. First launch and sign-in.

After installing, launch Antigravity from the app launcher. Expect a Google sign-in on first run: it opens your browser, you approve the account, and the browser hands you back to the app. If the hand-off loops or lands in the wrong app instead of Antigravity, that’s the known Linux OAuth bug — see “Common issues” below before reinstalling anything.

2. The 3 things you need to know:

  • Agent Manager is the home screen, not an editor. Antigravity 2.0 is a command center: you see every agent you’ve dispatched, what each one is doing, and which ones are waiting on your approval. The hands-on editor view is there when you want it, but the default posture is supervision, not typing.
  • Agents produce artifacts, not just chat. Every task yields reviewable evidence — an implementation plan before code is written, a task list ticked off as it goes, screenshots of the UI it changed, even a video recording of the agent clicking through your app in a browser. Read the artifact before you trust the code.
  • You can run several agents at once. Each agent works in its own workspace, so you can have one fixing a bug while another writes tests and a third researches a library. Check in on them from the Agent Manager instead of babysitting one conversation.

3. Your first task.

Pick a small, verifiable job: “add a test for X” or “fix this failing test and show me the passing run.” Give the agent the outcome, not the steps, then watch the plan artifact first — Antigravity drafts the plan before writing code, and you can edit the plan before it starts. Approve terminal commands when prompted; don’t blanket-approve them until you’ve seen what the agent actually runs.

4. Models and limits.

The free individual tier runs on Gemini models (Gemini 3.8 Flash is the workhorse on every plan) within weekly usage limits. Gemini 4 Argon and some third-party models (including Claude) are paid-plan only. If an agent suddenly stops mid-task with a quota message, you’ve hit the free-tier limit — wait for the reset or upgrade the Google AI plan; it’s not a bug in the app.

5. Config location.

Unverified on Omarchy — see the checklist above. After first launch, check ~/.config/ for the Antigravity directory and note it here before treating this section as settled.

Common issues & fixes

Sign-in loops forever

After approving Google in the browser, the antigravity-ide:// callback opens VS Code, then falls back to GNOME Software, and the app never receives the login. The session can also randomly unauthenticate later. This is a known, still-open Linux packaging gap (reported 2026-10-24): the official Linux build ships no registered handler for the antigravity-ide:// scheme, so xdg-open has nowhere to send the callback (forum thread).

Fix: On Omarchy, first try the repo package and a reboot. The reporter worked around it by switching to the community AUR build (antigravity-ide on the AUR), which ships a proper .desktop handler. If the loop reproduces, the fix is a desktop entry registering MimeType=x-scheme-handler/antigravity-ide; — verify the exact entry on a real machine before publishing this as a fix, and report it upstream either way.

App crashes on shutdown after the first run

SIGTRAP / coredump in the journal right after quitting. Reported once on Omarchy 4.0.6 with Antigravity 2.28.1 (2026-10-31): the main process aborted during language-server shutdown, then never reproduced on the next launch (forum thread).

Fix: Google’s response was to update — v2.29.0 shipped cold-start and window-restore fixes. If you see it on 2.33.0, it’s a one-off teardown crash, not a broken install: relaunch and move on, but note it if it repeats.

Gemini models hang on “Working…” forever

Gemini models hang on “Working…” and fail with “Agent execution terminated due to error”, while Claude models still work. This is the signature of a stale build: the bundled language-server certificate in v2.5.5 expired on 2026-11-03, and older Gemini models were retired at the same time (forum thread).

Fix: Update to a current build (omarchy update), then start a new conversation and pick a current model — model selection sticks per conversation, so an old chat keeps trying the retired model.

Blank or invisible window on first launch under Hyprland/Wayland

Standard Electron-on-Wayland behavior: Chromium defaults to the X11 backend through XWayland. (Arch install guide).

Fix: Launch with the native Wayland hint — antigravity --ozone-platform-hint=auto — and make it permanent by appending the flag to the Exec= line of the app’s .desktop entry if it reproduces. Confirm the flag and the binary name on Omarchy before publishing this as a fix.

The agent wants to run terminal commands and you’re not sure what’s safe

Not a bug — a setting. Antigravity added a Secure Mode (Dec 2025) in which agent actions require human review, and sandboxing for agent terminal commands on Linux (early 2026).

Fix: Keep approvals on for anything that touches the network, installs packages, or writes outside the project until you trust a given workflow. Review git diff before committing anything an agent wrote.

Antigravity is a free alternative to Cursor ($20/mo)

Antigravity is a free alternative to Cursor ($20/mo). What you give up: the mature single-editor flow Cursor has refined for years, and some model choice on the free tier (Gemini 4 Argon and third-party models need a paid Google AI plan). What you keep: an agent that plans, writes, runs, and verifies code with reviewable artifacts, multi-agent parallel work, and a browser that tests your app for you — free for individuals within weekly usage limits.

Honesty note: “free” here means free within Google’s usage limits, not unlimited. Free-tier users were moved to a weekly limit in Dec 2025, and heavy agent use will hit it. Cursor’s $20 buys predictable quota; Antigravity’s $0 buys the best free agent tier available, with a quota ceiling you’ll eventually feel.

How to switch from Cursor (~15 minutes)

  1. Export from Cursor: your code is just files on disk — there’s nothing to export. Your Cursor rules (.cursor/rules/) and chat history don’t transfer; copy any rules you care about into a text file.
  2. Import into Antigravity: open the same project folder in Antigravity. Paste your rules into the project’s instructions/knowledge base so agents pick them up. Re-create any custom commands as agent tasks.
  3. What doesn’t transfer: chat history, Cursor-specific rules formatting, and your Copilot-style inline completion habits — Antigravity wants you to delegate tasks, not accept ghost text.
  4. Time estimate: ~15 minutes to move a project over and run your first agent task.

Frequently asked questions

Does Antigravity work on Omarchy?

Yes — it’s in the official Omarchy repo as antigravity (v2.33.0-1, added 2026-11-20): omarchy pkg add antigravity. It’s a 208.4 MB download, 542 MB installed. Note this is the Antigravity 2.0 desktop app (the agent command center), not the separate Antigravity IDE editor — don’t confuse the two version lines.

Is Antigravity free?

For individuals, yes, within usage limits — no separate Antigravity subscription exists; it draws on your Google AI plan. Paid Google AI Pro and Ultra plans raise the limits and unlock extra models. A Google account is required.

How is Antigravity different from Cursor or Copilot?

Cursor and Copilot are editor-first: an AI helps you while you type. Antigravity is agent-first: you describe the outcome, one or more agents plan and execute it across the editor, terminal, and a browser, and each step produces a reviewable artifact (plan, task list, screenshot, browser recording) before you accept it.

Do I need a Google account?

Yes. Sign-in is via Google, and the agents run on Gemini models. The sign-in callback on Linux has a known bug (see Common issues) — if the browser hand-off loops, that’s the bug, not your account.

Can agents run commands on my machine?

Yes — that’s the point, and the risk. Agents get terminal access. Use Secure Mode / approval prompts, and the Linux sandbox option for agent commands, until you trust a workflow. Review git diff before committing anything an agent wrote.

How do I uninstall Antigravity?

omarchy pkg drop antigravity. Sign out first if you want the local session revoked; the uninstall removes the package, not your Google account or your projects.
