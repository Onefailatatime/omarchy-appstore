OpenRouter Ori on Omarchy

Ori is OpenRouter’s free CLI that signs you in once and then runs the coding agent you already use (Claude Code, Codex, OpenCode, omp, and more) on any of OpenRouter’s 600+ models, with one bill.

TL;DR

omarchy pkg add openrouter-ori
ori login
ori claude

That installs ori v0.17.4-1 (~55.9 MB download, ~118.7 MB installed, Apache-2.0 licence). The CLI is free; you pay OpenRouter per token at the model’s provider list price, plus a 5.5% fee when you buy credits on the Standard plan. Free models exist if you just want to try it.

Getting started (5 minutes)

1. Install and sign in.

After omarchy pkg add openrouter-ori, run ori login. It opens your browser for OAuth sign-in with your existing OpenRouter account. There is no API key to create or paste for interactive use: your models, credits, and org settings come with the login.

2. Launch the agent you already use.

Ori does not replace your agent; it runs it with OpenRouter wired in. The commands, keybindings, and flags stay the same:

ori claude      # Claude Code on OpenRouter
ori codex       # Codex CLI on OpenRouter
ori opencode    # OpenCode on OpenRouter
ori omp         # Oh My Pi on OpenRouter
ori hermes      # Hermes on OpenRouter

If the agent is not installed, ori prints the recommended install command and offers to install it for you. Run ori --help to see the full list for your version.

3. Three things worth doing in the first session:

  • Pick a model with --model. Without a model setting, Ori Code uses openrouter/auto, which routes to a model for you. Pass any OpenRouter model ID to choose: ori claude --model claude-opus-latest or ori codex --model gpt-5.2. Everything after the flags is forwarded to the agent untouched.
  • Try Ori Code, OpenRouter’s own agent. Run ori code (the native terminal coding agent, built for working with many models) if you do not have a favorite agent yet.
  • Make it the default with ori harness setup. A one-off ori <agent> command puts one session on OpenRouter. ori harness setup <agent> writes the OpenRouter settings into the agent’s own config, so the agent’s plain command runs on OpenRouter too. ori harness reset puts back what you had. Setup only works for the supported harness list, so check ori --help first.

Common issues & fixes

ori: command not found after installing

The installer puts the ori executable in your local binary directory, and that directory must be on PATH. This is documented in OpenRouter’s own install skill. (Install skill) Unverified on Omarchy: the Omarchy package may already handle PATH, so check before editing shell config.

Fix: Open a new shell first (the install may have updated your shell config), then check which ori. If it is still missing, find where the installer put it and add that directory to PATH in ~/.bashrc or ~/.zshrc.

ori login cannot open a browser

Headless session, SSH, or no default browser: the OAuth flow stalls because ori cannot launch one. (Install skill)

Fix: Run ori login --no-browser and open the printed URL yourself in any browser. The OAuth flow is the same; only the browser launch is skipped.

The agent bills the wrong model, or uses openrouter/auto when you wanted a specific model

Without a model setting, Ori Code defaults to openrouter/auto, which routes to a model for you. Note that some agents take their own model flag instead of ori’s: Grok Build uses ori grok -m, Crush uses ori crush run -m, Factory Droid uses ori droid exec -m or its model picker. (Ori Harness docs)

Fix: Pass the model explicitly every time: ori claude --model <model-id>. Check ori --help for your agent’s flag.

ori harness setup does nothing, or says the agent is not supported

ori harness setup only works for the harnesses in ori’s supported list (Claude, Codex, Cursor, Factory Droid, and others named in the docs). It does not configure any other app or IDE. (Ori Harness docs)

Fix: For an unsupported agent, keep launching it per session with ori <agent> instead.

Requests fail or stop working even though you have credits

First, run ori update and ori --version to make sure you are on the latest release. Then check your OpenRouter balance and the model you picked: free models are capped at 20 requests a minute and 50 a day (1,000 a day once your account has bought at least $10 of credits), and a model that is out of capacity or retired will fail until you pick another. (OpenRouter pricing) Unverified on Omarchy: not tested against a live account for this guide.

Fix: Update ori, check your balance, and pick a different model if the one you chose is out of capacity or retired.

  • Configure your agent directly against OpenRouter with an API key and a base URL (for example, ANTHROPIC_BASE_URL=https://openrouter.ai/api for Claude Code). Same models, same bill, no ori in the middle — but you lose the one-command model switching and org guardrails.

Ori is free — try any agent on any model for $0

Ori is free, and OpenRouter has a free tier: 25+ free models, capped at 50 requests a day (1,000 a day after you have bought $10 of credits). That is genuinely free coding-agent usage if you stick to free models — no subscription and no minimum on the Standard plan. The honest limit: free models are slower and weaker than paid ones, and the daily cap will stop a heavy session. The pitch that holds up: try any agent on any model for $0, then pay per token only when you want the good models. Paid usage is billed at the model’s provider list price, plus a 5.5% fee when you buy credits on Standard (8% on Business).

Frequently asked questions

Is Ori free?

The CLI is free (Apache-2.0). Model usage is pay-as-you-go: tokens are billed at the provider’s list price, and OpenRouter charges a 5.5% fee when you buy credits on Standard (8% on Business). Free models cost nothing within their daily caps.

Do I need an API key?

No, not for interactive use. ori login uses OAuth against your OpenRouter account, so there is no key to create or paste. API keys are still available on openrouter.ai if you want them for scripts.

Which agents does ori work with?

Claude Code, Codex, Grok Build, Hermes, OpenCode, Pi, omp, Prime Agent, Cline, Kilo Code, Muse Code, ZCode, Unreal Agent, Crush, Factory Droid, and DeepSeek Harness, with more on the way. Run ori --help for the list your version supports.

What is openrouter/auto?

The default model when you do not pick one. It routes your request to a model automatically, and you pay the rate of whichever model serves the request. Routing adds no fee.

Does ori replace my agent?

No. Ori launches the real agent CLI on your machine, with OpenRouter credentials and settings applied to that session. Your commands, keybindings, and flags stay the same.
