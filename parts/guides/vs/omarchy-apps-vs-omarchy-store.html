The short answer

Omarchy Apps (omarchyapps.com, this site) and Omarchy Store (omarchystore.com) are two different, independent websites run by different people. They have similar names because both help people find software for Omarchy. Neither one is the Omarchy project itself, which is made by Omacom.

The main difference is scope. Omarchy Apps lists only the packages in the official Omarchy repository and points you at Omarchy's own install command. Omarchy Store has a much larger catalog that also covers Arch and AUR software and themes, and it offers its own desktop app.

This page is written by the person who runs Omarchy Apps, so read it with that in mind. Every number about omarchystore.com below comes from files it publishes itself, linked in the table, and is dated.

Which one should you use?

  • Use Omarchy Apps if you want to stay with what the Omarchy maintainers ship in their own repository, see each package's source, PKGBUILD, license and version before installing, and install with the command Omarchy already gives you.
  • Use Omarchy Store if you want one place to browse a much bigger set of Linux apps and themes, including AUR software, and you are happy to install its desktop app to do it.
  • Either way, check what you install. The AUR is not vetted by the Arch team and anyone can upload to it, so read the PKGBUILD first. Updates on Omarchy should go through omarchy update, not a separate updater; see how to install apps on Omarchy.

If you just want to browse the official repo right now, start at the unofficial Omarchy store guide or the full catalog.

Frequently asked questions

Are Omarchy Apps and Omarchy Store the same site?

No. Omarchy Apps is at omarchyapps.com and Omarchy Store is at omarchystore.com. They are run by different people and are not connected.

Is either one the official Omarchy store?

No. Both are independent. Omarchy's own way to install software is the Install menu and the omarchy pkg add command, which install from the official repository at pkgs.omarchy.org.

Why does Omarchy Store list so many more apps?

It also lists software from the Arch repositories and the AUR, plus themes. Omarchy Apps lists only the official Omarchy repository, which had 213 packages on November 16, 2026.

Do I need a desktop app to use Omarchy Apps?

No. Omarchy Apps is a website. You copy the install command from a profile into a terminal, or use Omarchy's Install menu.
