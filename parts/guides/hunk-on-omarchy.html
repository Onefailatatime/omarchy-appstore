Hunk on Omarchy

Hunk is a review-first terminal diff viewer for agentic coders — a multi-file review stream with a sidebar, inline AI/agent annotations, and GitHub PR review built in. It’s for Omarchy users who review code their agents wrote (or anyone who reads diffs all day) and want a keyboard-driven reviewer instead of scrolling git diff output.

TL;DR

omarchy pkg add hunk
hunk --version   # should print 0.25.0

Takes ~2 minutes (69.7 MB download, 193.1 MB installed). Note: Hunk also ships as a default tool in Omarchy itself, installed through mise (per the README) — the store package is the standalone binary instead. Use one or the other, not both, so you don’t end up with two Hunks on your PATH.

Getting started (5 minutes)

1. First launch.

Run hunk with no arguments in any terminal and it prints help. The real entry point is a repo: cd into any git checkout and run:

hunk diff            # review current working-tree changes, including untracked files

You get a multi-file review stream with a sidebar listing every changed file, split or unified layout depending on terminal width, and syntax highlighting. Arrow keys move, Enter opens a file, Tab switches focus between the sidebar and the diff.

2. The 3 things you need to know:

  • hunk diff is the daily driver. hunk show reviews the latest commit, hunk show HEAD~1 an earlier one, hunk log opens an interactive history browser (press v to select a commit range, q back out to history). Add --watch to hunk diff and the review auto-reloads as your agent keeps editing files. Add --web and the same review opens in your browser instead of the terminal.
  • Press a to see what your agent thought. Agent annotations start hidden — a toggles them on, inline beside the code. To get them in the first place, install the review skill once (npx skills add modem-dev/hunk -g --skill hunk-review), open Hunk in another terminal, and ask your agent to use the hunk-review skill against the live session. No skill system? Ask the agent to run hunk skill show and follow the output.
  • Review PRs without the GitHub CLI. Hunk bundles hunk gh, so hunk gh pr opens the PR for your current branch, hunk gh pr 123 a numbered one, hunk gh commit a1b2c3d a commit, and hunk gh compare main...feature a comparison. Public repos work anonymously; set GH_TOKEN (or GITHUB_TOKEN) for private repos and higher API limits. As of 0.25.0 it also works with GitHub Enterprise Cloud (<tenant>.ghe.com).

3. Make it your Git pager.

One command and every git diff / git show opens in Hunk:

git config --global core.pager "hunk pager"

Prefer opt-in instead? Keep the default pager and add aliases:

git config --global alias.hdiff "-c core.pager=\"hunk pager\" diff"
git config --global alias.hshow "-c core.pager=\"hunk pager\" show"

Caveat from the README: untracked files appear only in Hunk’s own hunk diff loader — if you open git diff through the pager, Git decides the patch contents and untracked files won’t show. Jujutsu users set pager = ["hunk", "pager"] and diff-formatter = ":git" in jj config edit --user; Sapling users set pager = hunk pager in sl config -u.

4. Config location.

Preferences live in ~/.config/hunk/config.toml (or a repo-local .hunk/config.toml), for example:

theme = "github-dark-default"
mode = "auto"               # auto, split, unified
auto_split_min_width = 160  # minimum diff columns for split in auto mode
line_numbers = true
wrap_lines = false

Persistent state sits in ~/.local/state/hunk/state.json. Keybindings are remappable with a [keybindings] table in the same config file — see the keybinding guide on hunk.dev for the command list.

Practical notes: Press i on a changed PNG, JPEG, GIF, or WebP and Hunk draws the before/after images inline where “Binary file skipped” used to appear (new in 0.25.0). And hunk open browses the current directory (or hunk open README.md views one file, syntax-highlighted) with no repo required — i shows hidden/ignored entries there, e edits the displayed file in $EDITOR.

Common issues & fixes

Your shell alias or pager config broke after updating: Hunk rejects --fast as an unknown option

0.25.0 removed the --fast flag — it had been a no-op since 0.24.0 made worker highlighting the default.

Fix: Drop --fast from shell aliases, scripts, and pager configs (Git’s core.pager, LazyGit). (0.25.0 changelog)

hunk diff --web on a phone-width viewport scrolls sideways

The review page lays out at ~536px on a 390px screen. The terminal UI is unaffected.

Fix: Still open as of Nov 2026 (issue #1348). Use the terminal review on narrow screens, or a desktop-width browser window, until the fix lands.

Deeply nested filenames show only “…” in the Files sidebar

You can see the change counts but not which file it is.

Fix: Still open (issue #1344). Workaround: widen the terminal so the sidebar gets more room, or use hunk diff --web, where the file list has more space.

You can’t read a full commit message inside hunk log

Long messages are truncated with no way to expand them.

Fix: Still open as a feature request (issue #1343). Workaround: quit the review and read the message with git log / git show in the terminal.

Review comment threads can’t be resolved or reopened

There’s no resolve action, so discussion state is lost if you delete a thread.

Fix: Still open as a feature request (issue #1342). For now, threads are delete-only; keep the discussion in the PR itself if you need a resolved/unresolved record.

hunk diff --web --no-open | head -1 keeps the review running after head exits

The docs claimed stdout was exactly the URL, but piping it into another command stranded the process.

Fix: Fixed upstream (issue #1353, closed): Hunk now matches the terminal’s shutdown signals in headless reviews, so piping the URL into another command no longer strands the process. Update to a current build if you hit it.

hunk update doesn’t do what you expect on the Omarchy package install

hunk update is for npm, Homebrew, and install-script installs. The Omarchy package is managed by pacman.

Fix: Update it with omarchy update (or omarchy pkg add hunk again), not the self-updater. Unverified on-machine whether hunk update refuses or misbehaves on the packaged install; see the checklist.

Pairs well with / If you hate this, try

Pairs well with

  • Claude Code / opencode / any agentic coder — Hunk is the review half of the agent loop (the agent writes, Hunk is where you check). lazygit for staging and committing once the review is done — Hunk reviews, LazyGit stages. jj (Jujutsu) if you want native revsets in the same review UI.

If you hate this, try

  • delta — a pager, not a reviewer: beautiful git diff output in the terminal, no interactive stream. difftastic if you care most about structural diffs (it understands syntax, so a reformat doesn’t look like a rewrite). lumen is the closest sibling — also a review-first interactive TUI with mouse support and a sidebar, but no inline agent annotations.

Hunk is a free alternative to hosted AI code review

Hunk is a free alternative to hosted AI code review. Hunk is free and MIT-licensed — there is no paid tier, no trial, no feature gate. The honest framing: the paid thing it replaces is a seat in a hosted AI code-review tool (GitHub Copilot code review, JetBrains AI review, or a dedicated review bot subscription). Hunk plus the coding agent you already pay for covers the same loop — agent writes, you review with its annotations inline — for $0 extra. What you give up: the hosted tools’ automatic PR comments and team dashboards. What you keep: the actual review, in your terminal, with your agent’s notes attached to the lines they concern. GitHub’s own built-in PR review is also free for public repos, so Hunk’s pitch is the terminal workflow and the agent loop, not the price.

Frequently asked questions

Does Hunk work on Omarchy?

Yes — it’s in the official Omarchy repo as hunk (0.25.0-1, added 2026-11-23), and the README notes it also ships as a default Omarchy tool via mise. omarchy pkg add hunk installs the standalone binary; it needs only glibc.

Is Hunk free?

Yes. MIT-licensed open source, ~9,900 GitHub stars. No paid tier.

How do I review my agent’s changes?

cd into the repo and run hunk diff (add --watch while the agent is still working). Press a to show the agent’s inline annotations. Install the hunk-review skill once so the agent can annotate the live session: npx skills add modem-dev/hunk -g --skill hunk-review.

Can I review GitHub PRs with it?

Yes, without the GitHub CLI: hunk gh pr for the current branch’s PR, hunk gh pr 123 for a numbered one. Public repos work anonymously; private repos need GH_TOKEN or GITHUB_TOKEN. GitHub Enterprise is not supported (Enterprise Cloud <tenant>.ghe.com is, since 0.25.0).

Does it work with Jujutsu or Sapling?

Yes — it auto-detects jj and Sapling checkouts, and hunk diff / hunk show accept native revsets there. Set vcs = "git" / "jj" / "sl" in config to override detection.

How do I update Hunk?

If you installed from the store, update through the package manager (omarchy update), not hunk update — the self-updater is for npm/Homebrew/install-script installs.

How do I uninstall Hunk?

omarchy pkg drop hunk. If you set it as your Git pager, restore the default first: git config --global --unset core.pager (or point it at less).
