What Strata is, in one paragraph

Strata is a file manager for Linux made by LGSE. Its tagline is Navigate every layer. You browse in three ways: Miller columns like the Finder column view, an icon grid, or a sortable list. You find things with Ctrl + K, a search that starts showing results while it is still indexing. You look inside files with previews for Markdown, HTML, code, images, camera RAW, PDF, audio and video. It is written in Rust with GTK4, and the README says it is designed for Omarchy.

Screenshots: Appearance settings from the lgse/strata README (MIT), and the Strata page on this store.

Is Strata open source?

Yes. The LICENSE file in the lgse/strata repository is the MIT License, and the store listing marks it free-libre. There is no paid tier. The project moved to MIT in September 2026, so you may still see GPL-3.0-or-later on older pages.

One detail for packagers: by default the build embeds RARLAB's UnRAR code, which is not free software. The README documents a build flag that leaves it out.

Where the paid tools are ahead: ForkLift, Total Commander and Directory Opus are dual-pane managers with built-in sync and batch tools. Strata's own site says it has no independent split panes or file-content search yet, and that batch renaming works through custom actions. Those are real reasons to keep a two-pane tool. If you live in two panes, try flea too, or keep the paid tool on the machine you already own.

Try Strata on Omarchy

omarchy pkg add strata

Then press Ctrl + K and search for something you know you have. To make it your default, the Strata FAQ has the keybinding override for Super + Shift + F.

Frequently asked questions

Is Strata open source?

Yes. The Strata repository on GitHub is MIT licensed and there is no paid tier. Its default build embeds RARLAB's non-free UnRAR code, which packagers can leave out with a build flag.

Is Strata a ForkLift alternative?

For Linux, yes in spirit. ForkLift 4 is a paid macOS app, starting at $19.95 for a single user with one year of updates. Strata is free and runs on Linux. ForkLift has dual panes and many cloud connections; Strata focuses on Miller columns, search and previews.

Is there a Total Commander or Directory Opus for Linux?

Neither vendor lists a Linux desktop version on its site. Total Commander is Windows shareware at EUR 42 plus VAT after a 30-day trial, and Directory Opus supports x64 Windows 7 to 11. On Omarchy, Strata and flea are free keyboard-first options.

Does Strata have dual panes?

Not as independent split panes. The project site says so in its comparison table. Multiple Miller-column panes keep parent folders in view, but it is not a two-pane commander layout.

What do I need to run Strata?

64-bit Linux with glibc 2.39 or newer and GTK 4.12 or newer, on x86_64 or aarch64. On Omarchy, install it with omarchy pkg add strata.
