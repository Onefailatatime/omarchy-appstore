Antigravity CLI on Omarchy

Antigravity CLI (agy) on Omarchy is Google’s terminal coding agent: Gemini-powered, multi-file editing, subagents, and MCP tools, all from your shell, and the official replacement for the retired Gemini CLI.

TL;DR

omarchy pkg add antigravity-cli
agy

That installs Antigravity CLI (v1.5.15-1, ~98.5 MB download, ~273.9 MB installed). The command is agy, not antigravity. First run starts a Google Sign-In; a free Google account works on the free Individual plan. It takes about 2 minutes plus sign-in.

Getting started (5 minutes)

1. Sign in with Google.

Run agy from any project directory. The first run starts a one-time Google Sign-In flow. If you are on SSH or a headless session, it prints an authorization URL plus a one-time code instead of opening a browser.

2. Start an interactive session.

Running bare agy opens the full terminal UI: a scrollable conversation pane, a > prompt, and a status bar showing the active model, token usage, and any running subagents. Just describe the task in plain words.

3. Three things worth doing in the first session:

  • Know your mode. The CLI starts in Auto mode, which approves file edits and safe commands on its own and asks before anything riskier. Learn what Auto approves before you point it at a repo you care about; recent releases loosened these defaults, and remote agents now run commands without asking.
  • Check your quota before a big job. Antigravity meters work as “compute effort,” not transparent token counts, and the free tier has a weekly starter quota. A small question might cost 1 unit; a multi-file refactor might cost 50. The status bar shows a capacity percentage, but launch-era reports found it unreliable, so do not trust it blindly.
  • Add MCP servers for your tools. Antigravity CLI supports MCP, which extends it with real integrations. Add one with agy mcp add <name> <command>, list them with agy mcp list, remove one with agy mcp remove <name>. For example, CircleCI’s guide adds their server with agy mcp add circleci-cli circleci mcp start.

Config location: upstream docs do not state a single canonical path for where agy stores settings and auth, so this guide does not guess one — that is an open item on the on-machine verification checklist.

Common issues & fixes

You hit a rate limit after 20 to 30 minutes of use, and the CLI locks you out for days

This was widely reported at launch: free-tier users were locked out for up to 7 days after short sessions, and the capacity meter read 100% right before the lockout triggered. Google has since moved to 5-hour quota refreshes under a weekly cap, with paid AI-credit top-ups for Pro and Ultra subscribers. (Comparison, Nov 2026.)

Fix: If you hit the wall on the free tier, wait for the weekly refresh, or upgrade to Google AI Pro ($19.99/month) for the 5-hour refresh cycle.

agy is not found, or the command seems to be named something else

The binary is agy, not antigravity. Google’s own installer drops it in ~/.local/bin/; the Omarchy package should put it on PATH, but open a new terminal after install and run agy --version to confirm. (Binary name confirmed by Google’s docs and multiple install guides.)

Fix: If it is still missing, check pacman -Ql antigravity-cli | grep bin.

Sign-in fails or hangs on a remote machine with no browser

Antigravity CLI detects remote sessions and prints an authorization URL plus a one-time code. (DEV hands-on guide.)

Fix: Copy the URL into a browser on your own machine, sign in, and paste the code back into the terminal. Do not try to force a browser open over SSH.

The agent edits files or runs commands you did not expect it to

That is Auto mode doing what it is set to do: it approves file edits and safe commands without asking. (Auto mode behavior per CircleCI guide; the loosened defaults per Tailkits review, Nov 2026.)

Fix: If that is too loose for your repo, switch to a mode that asks first, and review the diff before you commit anything. Treat the agent like a junior dev with commit access: capable, but always reviewed.

You came from Gemini CLI and your old setup stopped working

That is expected, not a bug in this package. Google retired Gemini CLI for individual Google AI Pro and Ultra users on June 18, 2026. Antigravity CLI is its closed-source, Go-based replacement, sharing the same agent engine as the Antigravity 2.0 desktop app. Your old Gemini CLI config and extensions do not carry over automatically. (DEV hands-on guide.)

Fix: Install Antigravity CLI and sign in with Google; do not try to repair the retired Gemini CLI setup.

Pairs well with

  • A Google AI Pro subscription if you use it daily (the free weekly quota is thin for real work), git for reviewing every diff the agent makes, and MCP servers for the services you live in (CI, issue trackers, databases).

If you hate this, try

  • Claude Code for a terminal agent with clearer per-plan limits, or deepseek-dsh if you want an open-source harness you can point at any model, including local ones, with no Google account at all. Both are covered in their own guides on this site.

Antigravity CLI is free to start — the Individual plan costs $0

Antigravity’s Individual plan costs $0 and includes a baseline weekly agent quota, unlimited Tab completions, and unlimited Command requests. That makes it a genuine free way into a frontier terminal agent, with no credit card. The honest catch: Google publishes no numeric quota for any plan, the quota meters “compute effort” rather than tokens, and the free tier refreshes weekly, not every 5 hours like paid plans. So the pitch is: free to start, and free is enough to learn the tool, but free is not enough for heavy daily work. Paid capacity rides on Google AI plans, not a separate Antigravity subscription: Pro $19.99/month, Ultra $99.99 or $199.99/month. Prices as of November 2026; check antigravity.google/pricing before you pay.

Frequently asked questions

Is Antigravity CLI free?

Yes, the Individual plan is $0 with a weekly agent quota. Paid quota comes from Google AI Pro ($19.99/month) or Ultra ($99.99 or $199.99/month). There is no Antigravity-only subscription.

What happened to Gemini CLI?

Google retired it for individual users on June 18, 2026. It no longer works with a free Google sign-in and needs paid Gemini API or Gemini Code Assist access. Antigravity CLI (agy) is its replacement, built in Go instead of Node, with a smaller memory footprint and faster startup.

Is Antigravity CLI open source?

No. Unlike Gemini CLI, which was Apache 2.0, Antigravity CLI is closed source. Its GitHub repository holds a changelog, a readme, and a demo, but no source code.

Which models can I use?

Free and Plus tiers get Gemini 3.8 Flash, plus Claude Sonnet 4.6, Claude Opus 4.6, and GPT-OSS-120B until November 30, 2026, when Google plans to remove them. Google AI Pro adds Gemini 4 models (Neon, Argon, Hydrogen) and Claude Sonnet and Opus 5.5 on paid subscriptions. Model availability changes often; check the models page before you commit to a workflow.

Does agy update itself?

Upstream, yes: the Go binary updates itself in place, and you can trigger it manually with agy update. On Omarchy, the package manager may own the version instead, so check whether agy update and omarchy update disagree before relying on either. (Unverified on Omarchy; self-update per Real Python guide.)

Can I use it over SSH?

Yes. It detects remote sessions and falls back to an authorization URL plus a one-time code for sign-in.
