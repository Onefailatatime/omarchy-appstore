Omarchy Themes Backgrounds on Omarchy

Omarchy Themes Backgrounds on Omarchy is the stock wallpaper pack for Omarchy's built-in themes: the still images each theme cycles through, in one install.

TL;DR

omarchy pkg add omarchy-themes-backgrounds

That installs the background stills for the Omarchy themes (version 2026.11.25-1, 72.1 MB download, 72.8 MB installed, MIT). There is no app to launch. After install, cycle backgrounds with Super + Ctrl + Space or omarchy theme bg next.

Getting started (5 minutes)

1. Install it and check what arrived.

Run the install command above. Then list the files it delivered with pacman -Ql omarchy-themes-backgrounds to see which theme folders gained images. The images land in the stock theme directories, expected under /usr/share/omarchy/themes/<name>/backgrounds/, one folder per theme.

2. Pick a background.

Press Super + Ctrl + Space to open the background picker for your current theme, and choose one. Or cycle with omarchy theme bg next. To jump to a specific image, use omarchy theme bg set <path-to-image>, and to see the current one, run omarchy theme bg current. Switching themes with Super + Ctrl + Shift + Space or omarchy theme set <name> also changes the background to that theme's set.

3. Three things worth doing in the first session:

  • Add your own images. Copy any image into ~/.config/omarchy/backgrounds/<theme-name>/, for example ~/.config/omarchy/backgrounds/nord. Your images join the theme's bundled set in the picker without touching the stock files. The quickest route is Install, Style, Background in the Omarchy menu, which opens that folder for you.
  • Know the two background folders. Stock backgrounds live under /usr/share/omarchy/themes and get replaced on update, so never edit them there. Your own images live under ~/.config/omarchy/backgrounds/<theme-name>/ and survive updates.
  • Try a theme switch. Each theme ships its own backgrounds, and the current theme remembers the last background you chose for it. Switching themes restores that theme's last background, and re-applying the active theme can advance to the next image.

Common issues & fixes

You installed the package but no new backgrounds show up in the picker

The files may be there, but the picker looks the same — or you may be looking at the wrong theme.

Fix: First confirm the files actually arrived with pacman -Ql omarchy-themes-backgrounds. If the files are there but the picker looks the same, re-apply your theme with omarchy theme set <current-theme-name>: a theme change re-reads the background set, and re-applying an active theme can advance to the next image. If the picker still shows nothing new, check that you are looking at the right theme: each theme has its own folder, so a new nord background will not appear while tokyo-night is active. This step is unverified on a live machine, so treat it as the first thing to check, not a guaranteed fix. (Omarchy theme docs)

Your own image does not appear in the background picker

It is probably in the wrong folder.

Fix: User images belong in ~/.config/omarchy/backgrounds/<theme-name>/, not in the theme directory under /usr/share/omarchy/themes and not loose in ~/.config/omarchy/backgrounds/. The folder name must match the active theme exactly. Open Install, Style, Background in the Omarchy menu to open the right folder for the current theme, copy the image there, then open the picker again. (Omarchy comfort guide)

A short intro video plays every time you switch themes or backgrounds

Some themes pair a still background with a silent intro clip, matched by file name in backgrounds/intros/.

Fix: Toggle intro playback with omarchy theme bg intro toggle. This only affects the intro clips; it does not change the still backgrounds this package installs. (Omarchy theming docs)

You edited a stock background or deleted one, and an update wiped your change

That is by design: never edit anything under /usr/share/omarchy/themes, because an update replaces it.

Fix: The safe routes are an overlay (copy the theme folder to ~/.config/omarchy/themes/<name>/ and change files there) or your own backgrounds under ~/.config/omarchy/backgrounds/<name>/. Both survive updates. (Omarchy comfort guide)

Pairs well with

  • The Omarchy theme picker (Super + Ctrl + Shift + Space), community themes from omarchytheme.com, and your own photos in ~/.config/omarchy/backgrounds/<theme-name>/.

If you hate this, try

  • Your own images: drop them into ~/.config/omarchy/backgrounds/<theme-name>/ — you do not need this package at all. Or grab a curated set like dharmx/walls on GitHub, which the Omarchy manual itself points to — if you hate the stock wallpapers.

Frequently asked questions

What does this package actually install?

Background stills for the Omarchy themes: the wallpaper images each built-in theme cycles through. It is a data package, not an app, so there is nothing to launch.

Where do the files go?

Expected under the stock theme directories at /usr/share/omarchy/themes/<name>/backgrounds/. Confirm with pacman -Ql omarchy-themes-backgrounds after install, since the exact file list was not verified at draft time.

How do I change my background after installing it?

Press Super + Ctrl + Space for the picker, or run omarchy theme bg next to cycle, or omarchy theme bg set <path-to-image> for a specific file.

How do I add my own wallpaper?

Copy the image into ~/.config/omarchy/backgrounds/<theme-name>/ for the theme you use. It appears in the picker alongside the stock images. Use Install, Style, Background in the Omarchy menu to open the right folder.

Does installing this change my colors or theme?

No. It only adds still images. Colors come from the theme's colors.toml, which this package does not touch.

How do I remove it?

Run omarchy pkg remove omarchy-themes-backgrounds. Your own images under ~/.config/omarchy/backgrounds/ are untouched, since they live outside the package.
