HEY CLI on Omarchy

HEY CLI on Omarchy is Basecamp's official terminal interface for HEY email: a full-screen TUI plus scriptable commands for mail, contacts, calendar, and journal, with a skill and MCP server so coding agents can read and act on your HEY mail too.

TL;DR

omarchy pkg add hey-cli

Then run hey setup and hey tui. That installs HEY CLI (13.5 MB download, 40.6 MB installed, MIT; the app page did not list a version, and upstream was at 1.10.1 in early November 2026). hey setup walks you through a one-time browser sign-in, and hey tui opens the full-screen app. The CLI itself is free and open source, but it needs a paid HEY account: HEY for You is $99 a year after a 30-day free trial, and there is no free plan. HEY's own site says that on Omarchy 4.1 or later, hey is already installed and you just run hey — that is unverified, so if hey is not found, install it with the command above.

Getting started (5 minutes)

1. Sign in.

Run hey setup. It walks you through setup and opens your browser once so you can sign in to HEY and approve access, then everything after that happens in the terminal. Check the session any time with hey auth status, and sign out with hey auth logout (hey login and hey logout are shortcuts). Run hey setup again any time to rerun the wizard. If you only want the HEY command and do not want agent integrations, run hey setup --skip-agents.

2. Open the TUI.

Run hey tui. It is a full-screen terminal app for Mail, Contacts, Calendar, and Journal, using HEY's own keyboard shortcuts, and it keeps mail and calendar data updated through live connections. If the connection drops, it shows an offline status and reconnects. The TUI is for browsing; the plain commands are for when you know what you want, or for scripts.

3. Three things worth doing in the first session:

  • Try the scriptable commands. hey search "invoice" searches threads, and most commands accept --json for full structured output or --jq '<expression>' to filter it, so you can pipe results into scripts. Bare hey prints the help, and hey commands --json lists every command with its notes for agents.
  • Connect your coding agent. The CLI ships with an agent skill and a Claude Code plugin. Run hey setup claude for the skill and the HEY plugin for Claude Code, hey setup codex for the skill in Codex, or hey skill install for just the skill with any other agent. Want HEY as MCP tools instead? hey mcp serves them from your signed-in CLI; add it to Claude Code with claude mcp add hey -- hey mcp.
  • Know the fix-it command. If the TUI will not open or mail stops updating, run hey doctor. It checks whether you are still signed in, whether your login is stored securely, and whether you are on the latest version, with a fix alongside anything that is wrong.

Common issues & fixes

The TUI will not open, or mail stops updating

The TUI refuses to open, or mail stops updating in the terminal.

Fix: Run hey doctor. It checks your sign-in, your credential storage, and your version, and suggests a fix for whatever it finds. Do not reinstall first; hey doctor is the documented first step for exactly this symptom. (HEY help, HEY TUI)

You installed with the curl pipe and nothing happens, or setup never runs

The installer finishes, but setup never runs and nothing happens.

Fix: The install command pipes a script through bash, so bash has no interactive input terminal during installation, and the installer finishes safely instead of trying to open a setup prompt. Start setup yourself with hey setup, or run bare hey, which starts the setup flow on first run when you are logged out. (This applies to the upstream installer; the Omarchy package may already handle it, which is an open verify item.) (Flavio Copes HEY CLI guide)

hey auth status reports a storage problem instead of saying you are logged out

Signing in again does not fix it.

Fix: On macOS, hey-cli stores credentials in the system Keychain, and if the Keychain refuses a read, for example inside an agent's sandbox, it reports a storage problem rather than a logged-out state. Signing in again will not fix it, so look at what is blocking Keychain access. On Linux the credential path is unverified; check ~/.config/hey-cli/ for a credentials file as a first step. (Flavio Copes HEY CLI guide)

You expected hey-cli to work with your Gmail address

It will not.

Fix: HEY is its own email service with its own @hey.com address; there is no IMAP, and you cannot use your existing address except by forwarding mail into HEY. HEY for You is $99 a year after a 30-day free trial with no card, and there is no free plan. If you want terminal email on your current address, use aerc or neomutt with an IMAP provider instead. (HEY vs Fastmail comparison, HEY alternatives)

Setup connected coding agents you did not want it to touch

Setup connected agents you did not ask it to connect.

Fix: Setup connects the agents it finds on your machine by default. Skip that step with hey setup --skip-agents, or set HEY_SETUP_AGENT=none on the install command. To connect one agent later, run hey setup claude or hey setup codex on its own. (Flavio Copes HEY CLI guide)

Pairs well with / If you hate this, try

Pairs well with

  • Claude Code (the HEY skill and MCP server let it read, search, draft, and organize your mail in plain language), your HEY Calendar (same account, same TUI), and shell scripts (structured --json output makes mail searchable from cron jobs and agents).

If you hate this, try

  • aerc or neomutt for terminal email with any IMAP provider for free, and thunderbird (Thunderbird) as the free GUI option — if you hate the paid-account requirement. If you like HEY's Screener idea but not its price, Fastmail Individual is $60 a year and includes your own domain.

There is no free HEY

There is no free HEY. The CLI is free and MIT licensed, but the service it talks to costs $99 a year after a 30-day trial, with no free plan and no monthly billing. If you want terminal email without paying, use aerc or neomutt with a free or cheap IMAP provider instead. What you give up: HEY's Screener, Imbox, Feed, and Paper Trail workflow, and the agent skill built for it. What you keep: fast keyboard-driven mail in the terminal, for $0.

How to switch from HEY to a free terminal mail setup

  1. Export from HEY: HEY exports mail as MBOX and contacts as vCard. Export before you stop paying, since your @hey.com mail is forwarded for life after one paid year but the account itself closes.
  2. Import into the new setup: import the MBOX file into Thunderbird or Fastmail, and point aerc or neomutt at the new IMAP account. The vCard file carries your contacts across.
  3. What doesn't transfer: the Screener decisions, the Imbox/Feed/Paper Trail organization, and the HEY agent skill and MCP server, which only work with a HEY account.
  4. Time estimate: about 30 minutes to export and import, plus time to learn the new client's keys.

Frequently asked questions

Does hey-cli work with Gmail?

No. It only works with a HEY account. HEY has no IMAP, so there is no way to point it at Gmail or any other provider. You can forward mail from another address into HEY, but the account itself is a @hey.com address.

Is HEY free?

No. HEY for You is $99 a year, billed yearly only, after a 30-day free trial with no card. HEY for Families is $179 a year for up to five people, and HEY for Domains is $12 per user a month ($10 for the first user) on your own domain. There is no free plan.

Is hey already installed on Omarchy?

HEY's own site says that if you are running Omarchy 4.1 or later, it is already installed and you just run hey in the terminal. This is unverified on a live Omarchy machine; if hey is not found, install it with omarchy pkg add hey-cli.

Where does hey-cli store my login?

On macOS it uses the system Keychain, falling back to ~/.config/hey-cli/credentials.json if the keyring is unavailable. The Linux storage path is unverified; that is an open item on the checklist.

Can Claude Code read my HEY mail?

Yes. Run hey setup claude to install the skill and the HEY plugin for Claude Code, or serve HEY as MCP tools with hey mcp. Then Claude can read, search, draft, and organize your mail in plain language.

What does hey doctor do?

It checks whether you are still signed in, whether your login is stored securely, and whether you are on the latest version, and suggests a fix for anything it finds. Run it first whenever the TUI will not open or mail stops updating.
