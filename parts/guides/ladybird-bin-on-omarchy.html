Ladybird on Omarchy

Ladybird on Omarchy is the first public alpha of a truly independent web browser: its own engine built from scratch, no Chromium, no Google, and no monetization, but it is alpha software and not a daily driver yet.

TL;DR

omarchy pkg add ladybird-bin

Then run ladybird. That installs Ladybird (145.9 MB download, 382.9 MB installed, BSD-2-Clause and LGPL). It is an alpha released 2026-11-23 (upstream alpha version 2026.47.7; the store page lists no version number, so the packaged version is unconfirmed). Try it to see the web on a brand-new engine, and keep Firefox or Chromium as your real browser.

Getting started (5 minutes)

1. Run the first-run setup.

On first launch Ladybird walks you through setup: pick a light or dark theme, pick an accent color, and choose a tab layout (top tabs or vertical tabs). Then it asks about the built-in ad and tracker blocker: leave it on. Finally, pick a search engine. There is no default: choose from Google, Bing, Brave Search, DuckDuckGo, Ecosia, Kagi, Mojeek, Startpage, Yahoo, or Yandex, or add a custom one.

2. Load a site you know well.

Try a plain site first, like a news homepage or a docs page. For an alpha, rendering is surprisingly good: hands-on tests found pages render nearly as well as Blink and WebKit, with only small differences like wavy text underlines drawing as zigzags. If a site looks wrong, that is useful data, not a failure on your part.

3. Three things worth doing in the first session:

  • Try the built-in tools. Ladybird ships a screenshot tool (selected area, visible page, or full page), a PDF viewer with annotation, forced dark mode for sites without one, and Global Privacy Control. All of it is built in, no extensions needed, because extensions do not exist yet.
  • Use per-site settings. The toolbar has a button to switch ad blocking off for the current site, and per-site settings live in the same place. If a site breaks, try it with the blocker off before concluding the engine cannot render it.
  • Report what breaks. The project explicitly asks for this: if you build websites, try yours in Ladybird and tell the team what breaks. It supports WebDriver for automated testing and the Firefox DevTools protocol. File issues at github.com/LadybirdBrowser/ladybird.

Common issues & fixes

A website looks broken, loads wrong, or a feature does not work

Ladybird's engine, LibWeb with the LibJS JavaScript engine, is built from scratch, so sites that were only ever tested against Blink, WebKit, or Gecko can break in ways no other browser shows.

Fix: This is expected in an alpha. Try the site with the content blocker off first, since a blocked script can look like an engine bug. If it still breaks, report it to the project with the URL and what you expected: that report is the point of the alpha. (Ladybird alpha hands-on)

The browser crashes, sometimes on ordinary pages

Ordinary pages can crash the browser.

Fix: Also expected. The alpha announcement says plainly that some websites will not work and the browser will sometimes crash. Restart and try again, and if a specific page crashes it reliably, report it upstream with the URL. Do not use Ladybird for anything you cannot afford to lose to a crash. (Ladybird alpha coverage)

Your favorite extension is not available, and there is no extensions menu

Extensions do not exist yet in Ladybird, and neither do PWAs, so a site you use as an installed app cannot be installed here.

Fix: The built-in ad blocker, screenshot tool, PDF viewer, and forced dark mode cover the most common extension jobs. If your workflow depends on a password manager or a specific extension, keep Firefox or Chromium as your daily driver and use Ladybird for testing. (Ladybird alpha coverage)

No search engine is set, and searches from the address bar go nowhere

Ladybird ships with no default search engine on purpose: the project takes no search deals and no other monetization.

Fix: Pick one during first-run setup, or change it later in Settings. Google, DuckDuckGo, Brave Search, Kagi, and Startpage are all in the list, and you can add a custom engine. (Ladybird alpha hands-on)

You are unsure whether it is safe to log into your email or bank in Ladybird

Do not.

Fix: The alpha announcement is direct: a new browser gets hacked over and over, and the project makes no promises about security today. Its process isolation is still being hardened, and the browser process does not yet treat every request from the WebContent process as untrusted. Use test accounts and staging sites only, keep it away from secrets, and do your real logins in Firefox or Chromium. (Ladybird alpha testing guide)

Pairs well with / If you hate this, try

Pairs well with

  • Firefox or Chromium as your daily driver (Ladybird is a second browser for now), and WebDriver or the Firefox DevTools protocol if you test websites.

If you hate this, try

  • firefox (Firefox) — the independent-engine browser that is ready today, or chromium (Chromium) — the stable Blink option. Check back on Ladybird when the beta lands in 2027 — if you hate the crashes and missing sites.

Ladybird is a free alternative to Google Chrome ($0, but your data is the product)

Ladybird is a free alternative to Google Chrome ($0, but your data is the product). What you give up: stability, extensions, PWAs, and any security promise at all, because this is an alpha. What you keep: a full browser with a built-in ad blocker, a real choice of search engine, and an engine owned by a non-profit, not an ad company.

Be honest about the trade: Ladybird is not a Chrome replacement yet, and the project says so itself. The free-alternative pitch here is about the future, not today. If you switch to Ladybird as a daily driver now, you will hit broken sites and crashes. The honest recommendation is to run it beside Firefox or Chromium, report what breaks, and help it become a real alternative. A beta is planned for 2027 and a stable release for 2028.

How to switch from Google Chrome (~2 minutes to install; a real switch is not recommended yet)

  1. Export from Chrome: export bookmarks from the Bookmark Manager (Ctrl + Shift + O, then the three-dot menu, Export bookmarks) as an HTML file. Passwords export from chrome://settings/passwords under the three-dot menu, as a CSV file. Treat that CSV as sensitive and delete it after importing.
  2. Import into Ladybird: Ladybird's import story is still thin in the alpha, and no verified import path from Chrome is documented yet, so do not promise one. For now, keep Chrome or Firefox installed for your passwords and use Ladybird for casual browsing and testing.
  3. What doesn't transfer: extensions, PWAs, Google account sync, saved payment methods, and any Chrome-only feature. The built-in ad blocker and PDF viewer cover part of that gap.
  4. Time estimate: the install takes about 2 minutes. A real switch is not recommended yet, so treat this as a trial, not a migration.

Frequently asked questions

Is Ladybird free?

Yes. It is open source, and the project is backed by a 501(c)(3) non-profit funded entirely by donations and sponsorships. It takes no search deals, no crypto tokens, and no other monetization.

Is Ladybird ready to replace Chrome or Firefox?

No. It is a first alpha, released 2026-11-23. Some websites will not work, the browser will sometimes crash, and the project makes no security promises today. A beta is planned for 2027 and a stable release for 2028.

What engine does Ladybird use?

Its own. LibWeb is the rendering engine and LibJS is the JavaScript engine, both built from scratch. It is not a fork of Chromium, WebKit, or Gecko.

Does Ladybird support extensions?

Not yet. There is no extension support and no PWA support in the alpha. Built-in tools cover ad blocking, screenshots, PDFs, and forced dark mode.

Is Ladybird safe to log into accounts with?

No, not yet. The project says a new browser gets hacked over and over and makes no security promises today. Use test accounts only and keep your real logins in another browser.

Does Ladybird run on Windows?

Not in this alpha. macOS (Apple Silicon) and Linux (x86-64 and Arm64) are supported. Windows support is planned later.
