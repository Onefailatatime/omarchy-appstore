Install Strata in one line

If you only read one thing: Strata is in the Omarchy package repository, so one command installs it and keeps it updated with the rest of your system.

omarchy pkg add strata

Open it from the app launcher (Super + Space, type Strata) or run strata in a terminal. The Strata page on this store shows the current version, size and source.

The five keys worth learning first

These come from the default key map in the Strata README. Press F1 inside the app for the full reference.

KeyWhat it does
Ctrl + KRecursive search by file name or path across Home and mounted local drives
Ctrl + LType a path, or an address like smb://server/share or sftp://user@host/path
Ctrl + FFilter the current pane

F2Rename

Frequently asked questions

What is Strata?

Strata is a keyboard-first file manager for modern Linux desktops, made by LGSE. It has three views: navigable Miller columns, an icon grid and a sortable list. It adds fast filename search, rich previews and Omarchy theme following.

Is Strata free and open source?

Yes. The LICENSE file in the lgse/strata repository is MIT, and there is no paid tier. The project switched to MIT in September 2026, so older pages may still mention GPL-3.0-or-later.

How do I install Strata on Omarchy?

Run omarchy pkg add strata in a terminal. It comes from the Omarchy package repository and updates with the rest of your system. The project also has its own interactive installer for Arch Linux.

What does Strata need to run?

64-bit Linux with glibc 2.39 or newer and GTK 4.12 or newer. Release builds exist for x86_64 and aarch64. Arch Linux and Omarchy are the primary supported environments, and it is designed for Wayland.

How do I make Super+Shift+F open Strata instead of Nautilus?

On current Lua-based Omarchy releases, back up ~/.config/hypr/bindings.lua, then append overrides that unbind SUPER + SHIFT + F and bind it to launch strata. Run hyprctl reload and hyprctl configerrors to check. These user overrides survive Omarchy updates.

Does Strata search inside files?

No. Ctrl+K is fast filename and path search, not file-content search. The README calls this a deliberate tradeoff. By default each search walk stops at 10 seconds and 200,000 entries, and you can raise or remove those limits in Settings.

Why does a preview say Preview unavailable?

Image, RAW, PDF, thumbnail and media previews run in a separate Bubblewrap sandbox. If the sandbox is missing, a parser crashes or a limit is hit, Strata shows a normal icon or Preview unavailable instead of running the parser unprotected. Make sure bubblewrap is installed. Video thumbnails also need ffmpegthumbnailer or ffmpeg.

Is it safe to preview files I downloaded?

Strata treats files as untrusted. Native parsers run out of process with no network, no capabilities, a read-only runtime and resource limits. Plain text and source previews stay in process but are capped at 1 MiB.

Can Strata follow my Omarchy theme?

Yes, on Omarchy Quattro. Open Settings, then Appearance, and turn on Follow Omarchy. Strata then updates live when you change the Omarchy theme. You can also pick a bundled theme or build your own, saved as TOML in ~/.config/strata/themes/.

Can it open network shares?

Yes. Press Ctrl+L and enter an smb:// or sftp:// address. Strata uses GIO/GVfs and asks for credentials when needed. SMB needs the gvfs-smb backend on Arch.

How does Strata update?

It checks for updates by default and never downloads or installs one without your confirmation. If you installed it from the Omarchy package repository, it checks that repository. You can choose Stable, Preview or Nightly channels in Settings, then Updates.

Strata or flea?

Both are free, keyboard-first file managers listed on this store. Strata is Rust and GTK4 with Miller columns and sandboxed previews. flea is Rust with a Quickshell front end built for Omarchy. Our Strata install guide compares them side by side.
