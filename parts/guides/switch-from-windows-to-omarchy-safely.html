1. Try it in a window

Try Omarchy for Windows runs Omarchy in a virtual machine on your PC, so you can explore apps, themes and the keyboard flow without repartitioning. Per its README you need 64-bit Windows 10 or 11 with hardware virtualization; ARM64 Windows PCs are not supported. The launcher is about 10 MB, and setup downloads about 2 GB. Your Linux files persist between sessions.

Image from the omacom/try-omarchy-windows README (MIT).

2. Back up and write things down

  • Copy your files to an external drive: Documents, Desktop, Pictures, Downloads, game saves you care about.
  • Note your license keys. If your PC shipped with Windows, omarchy windows key can print the OEM key from firmware later.
  • Check your password manager works on another device.

3. Install next to Windows

The safest move keeps Windows on the disk. In short: turn off BitLocker and Fast Startup, shrink C: in Disk Management, then choose Free space install in the Omarchy installer and run limine-scan afterward. The dual boot guide has every click.

4. Bring your trial setup over

If you used Try Omarchy, the project's migration guide says one command in your new Omarchy install reads the trial straight off the Windows drive. Open a terminal with Super + Return:

curl -fsSL https://tryomarchy.com/import | bash

It asks for your password, finds the trial, and lets you pick what comes over: settings, themes, keybindings, apps, files and projects. The guide says nothing on the Windows drive is changed. Keep Try Omarchy installed until the import is done, because uninstalling it deletes the trial.

6. Your way back

  • Windows is still there. Pick Windows Boot Manager in the Limine menu.
  • A bad Omarchy update: boot the previous snapshot from Limine. Snapshots cover the system, not your files.
  • Help: run omarchy-debug and share it in #omarchy-help on the Omarchy Discord.

Frequently asked questions

Can I try Omarchy without leaving Windows?

Yes. Try Omarchy for Windows runs Omarchy in a window on 64-bit Windows 10 or 11 with hardware virtualization. ARM64 Windows PCs are not supported.

Will I lose Windows if I install Omarchy?

Not if you choose Free space install. Windows stays on the disk and you add it to the Limine boot menu with limine-scan.

How do I move my Try Omarchy setup to a real install?

After installing next to Windows, run curl -fsSL https://tryomarchy.com/import | bash in Omarchy. It reads the trial from the Windows drive and lets you pick what to bring.

Why turn off Fast Startup before installing?

Omacom's migration guide says that with Fast Startup on, Windows never fully shuts down, so Omarchy would only see an out-of-date copy of your files.

How do I get back to Windows?

Choose Windows Boot Manager in the Limine boot menu. Run limine-scan in Omarchy if it is missing.
