Put every launcher in one place

Omakade is a game library for Omarchy that gathers what you have installed across Steam, Lutris, Heroic, RetroArch, Battle.net and more into one cover-art view. Heroic has its own page too, and the Minecraft Launcher page explains what you need to buy to play.

Keep the Windows PC as a game server

If a game will not run on Linux, you do not have to give it up. Omarchy preinstalls Moonlight, so you can stream from a Windows PC running Sunshine. The manual says that when both machines are wired, it feels like playing locally, and suggests native resolution, 120Hz and maximum bitrate. Pair Xbox controllers over Bluetooth after Install > Gaming > Xbox Controllers.

Frequently asked questions

Can I play Steam games on Omarchy?

Yes. Install Steam from Install > Gaming > Steam. Valve's Proton layer runs tens of thousands of Windows games on Linux.

Does Fortnite work on Omarchy?

Not natively. The manual suggests Xbox Cloud Gaming or GeForce NOW, or streaming from a Windows PC with Moonlight and Sunshine.

How do I play Epic Games Store games?

Install Heroic from Install > Gaming. It runs Epic titles that do not rely on anti-cheat, plus GOG and Amazon Prime Gaming games.

Do Xbox controllers work?

Yes. Add support with Install > Gaming > Xbox Controllers, then pair over Bluetooth with Super+Ctrl+B. Wired USB-C controllers need nothing extra.

Are NVIDIA drivers set up?

Yes. omarchy.org says NVIDIA drivers are set up during install.
