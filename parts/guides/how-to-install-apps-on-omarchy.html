Install from the official Omarchy package repository first

The simplest path is a package already published by Omarchy. Search this directory, open the app profile and review its project link, license, requirements and package source. Then copy the displayed command:

omarchy pkg add <package-name>

Use the exact package name from the profile. Names ending in -bin commonly install a prebuilt upstream binary, while another package may build from source or package a different release channel. Read the profile instead of guessing which variant you want.

This website does not download or serve the package. The command hands installation to Omarchy and its configured package sources.

When an app is not in the Omarchy repository

The official manual recommends checking the Omarchy Menu under Install → Package, then looking for an Arch package and, if necessary, the AUR. The AUR is powerful because the community can describe how to build software that is not in the official repositories, but it deserves more review—not less.

  1. Prefer the project's official website or repository when choosing a package name.
  2. Read the PKGBUILD and associated install scripts before building an unfamiliar AUR package.
  3. Check the maintainer, recent comments, update history and source URLs.
  4. Be skeptical of install instructions that pipe a remote script directly into a shell.
  5. Confirm whether the application needs filesystem, microphone, camera, network or background-service access.

A 60-second package safety check

Ask four questions: Is this the real upstream project? Does the package download from a source I recognize? Does its license and version match what I expect? Are its requested permissions reasonable for the job? A repository listing is useful distribution metadata, not a guarantee that software is risk-free.

Update Omarchy through Omarchy

For a full system update, use the Omarchy Menu's update flow or the documented Omarchy update command. The official manual warns that a direct pacman -Syu or yay -Syu skips the snapshot, migrations and coordinated configuration work Omarchy performs around an update.

Before removing an app, record any data location or export format you need. Removing a package and deleting your personal application data are separate operations; do not erase a configuration directory unless you know it contains nothing you want to keep.

Frequently asked questions

What command installs a package from the Omarchy repository?

Package profiles in this directory provide a copyable omarchy pkg add command using the exact current package name.

Can I use pacman and the AUR on Omarchy?

Yes. Omarchy is Arch-based, and its manual points users to Arch packages and the AUR when needed. Full system updates should still go through Omarchy's update flow.

Does the Unofficial Omarchy App Store host packages?

No. It is a directory. Install commands retrieve software through Omarchy and the configured package sources, not from this website.
