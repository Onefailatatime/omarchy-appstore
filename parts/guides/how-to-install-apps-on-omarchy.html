What is the quickest way to install apps on Omarchy?

Press Super + Space, choose Install, then Package. Type to filter, press Tab on each package you want, then press Enter to install them all together. In a terminal, list several names in one command:

omarchy pkg add flea strata rustdesk

For the AUR, use Install, then AUR in the same menu. Update everything with Update, then Omarchy, not with pacman -Syu.

How do I install one app from the Omarchy menu?

  1. Press Super + Space to open the Omarchy menu.
  2. Choose Install, then Package.
  3. Start typing the name. The list filters as you type.
  4. Highlight the package and press Enter. Omarchy asks for your password, then installs it.

The bottom part of the picker shows the package details, so you can read what it is before you install. Handy keys inside the picker:

How do I install multiple packages at once on Omarchy?

This is the part most guides skip. The Install, then Package picker is a multi select list.

  1. Open Super + Space, then Install, then Package.
  2. Type the first name, highlight it and press Tab. It gets a green marker.
  3. Clear the search, type the next name and press Tab again. Repeat for as many as you like.
  4. Press Enter once. Omarchy installs every marked package in a single run.

The AUR picker (Install, then AUR) works the same way, and it also lets you press Alt + B to read a package's PKGBUILD before you install it.

How do I install apps from the terminal?

Use the exact package name from its profile on this site:

omarchy pkg add <package-name>

For several, put them on one line with spaces. For example flea, strata and rustdesk:

omarchy pkg add flea strata rustdesk

omarchy pkg add skips anything you already have, then checks that each package really installed and tells you by name if one didn't.

Names ending in -bin usually install a prebuilt release from the upstream project. Other variants may build from source or follow a nightly channel. Read the profile instead of guessing.

This website does not download or serve any package. The command hands installation to Omarchy and its configured package sources.

What if an app isn't in the Omarchy repository?

Check Install, then Package first. If it isn't there, try Install, then AUR, or an AUR helper such as yay. The AUR isn't vetted by the Arch team, and anyone can upload to it. So before you build something unfamiliar:

  • Prefer the project's own site or repo when picking the package name.
  • Read the PKGBUILD (Alt + B in the AUR picker).
  • Check the maintainer, recent comments and update history.
  • Be careful with install steps that pipe a remote script straight into a shell.

How do I remove packages on Omarchy?

From the menu: Super + Space, then Remove, then Package. It works like the install picker, so Tab marks several and Enter removes them all, along with their config files and unused dependencies.

From the terminal:

omarchy pkg drop <package-name>

omarchy pkg drop takes several names too and quietly skips any that aren't installed. Removing a package is not the same as deleting your own data, so export anything you want to keep first.

How do I update apps on Omarchy?

Use Update, then Omarchy in the menu, or click the circle arrow next to the clock when a release is out. In a terminal, run:

omarchy update

This pulls the latest Omarchy configs, runs migrations and updates your packages together. The manual advises against running pacman -Syu or yay -Syu yourself, because you can miss the config changes newer packages need. If an update ever goes wrong, restart and pick the pre update snapshot from the boot menu.

A 60 second package check

Is this the real upstream project? Does it download from a source you recognize? Do the license and version match what you expect? Are the permissions it asks for reasonable for the job? A repository listing is useful, but it isn't a guarantee.

Frequently asked questions

How do I install multiple packages at once on Omarchy?

Open the Omarchy menu with Super + Space, choose Install, then Package, press Tab on each package you want, then press Enter. Or run omarchy pkg add followed by all the names, separated by spaces.

Is there a GUI app store for Omarchy?

The built in way is the Omarchy menu: Install, then Package or AUR, a searchable list with a details preview. This site is an unofficial directory on top of that, so you can browse by category, read profiles and copy the exact install command.

What is the shortcut for the Omarchy menu?

Super + Space.

What is the difference between Install, Package and Install, AUR?

Package lists the official Arch repositories and the Omarchy Package Repository. AUR lists community packages that aren't vetted by the Arch team, so read the PKGBUILD first.

How do I uninstall an app on Omarchy?

Choose Remove, then Package in the Omarchy menu (Tab to pick several), or run omarchy pkg drop <name> in a terminal.

Can I use pacman and yay on Omarchy?

Yes for installing. For full system updates, use Update, then Omarchy, or omarchy update, so migrations run with the new packages.

Does the Unofficial Omarchy App Store host packages?

No. It is a directory. Install commands go through Omarchy and its package sources, not this site.
