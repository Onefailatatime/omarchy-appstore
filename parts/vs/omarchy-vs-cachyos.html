Should I pick Omarchy or CachyOS?

Omarchy suits you if

  • You like working from the keyboard and want a tiling desktop without building it yourself.
  • You want one opinionated setup with themes, hotkeys and a menu (Super + Space) for installing, updating and tweaking.
  • You're fine with a Limine boot menu and full disk encryption by default. Omarchy can take a whole drive or install into free space next to Windows.[omarchy.org]

CachyOS suits you if

  • You want packages compiled for newer CPUs. The CachyOS wiki says x86-64-v3 builds give a 5% to 20% uplift over generic x86-64, depending on workload.[wiki.cachyos.org]
  • You want to pick your desktop at install time, with 17 or more desktops and window managers on offer.[cachyos.org]
  • You want kernel choices, like linux-cachyos with the BORE scheduler, sched-ext, BMQ and RT options.[cachyos.org]

How do you install and update apps on each?

OmarchyCachyOS
Install apps (GUI)Omarchy menu: Install, then Package or AUR [omarchy.org]Shelly or Octopi [wiki.cachyos.org]
Install apps (terminal)omarchy pkg add <name>sudo pacman -S <name>
UpdateUpdate, then Omarchy, or omarchy update [omarchy.org]sudo pacman -Syu, Shelly or Octopi [wiki.cachyos.org]

On Omarchy, every package in the official Omarchy repository has a profile on this site with its exact omarchy pkg add command. See how to install apps on Omarchy, including installing several at once, or start with the best Omarchy apps to install first. Since both are Arch based, most apps you'd install on one exist for the other. The commands just differ.

How can I try each one?

Omarchy: download the ISO from omarchy.org, write it to a USB stick (the manual suggests balenaEtcher on Mac or Windows, caligula on Linux), turn off Secure Boot and TPM, and boot from the stick. To keep Windows, shrink a partition first and pick the free space install when the installer asks.[omarchy.org]

CachyOS: download the ISO from cachyos.org, write it to a USB stick and boot from it. The installer pulls packages online, so keep a wired or solid wifi connection.[wiki.cachyos.org]

Not sure your CPU gets CachyOS's optimized builds? The CachyOS wiki gives this check:

/lib/ld-linux-x86-64.so.2 --help | grep supported

If you see x86-64-v4 (supported, searched), your CPU can use the v4 repos.[wiki.cachyos.org]
