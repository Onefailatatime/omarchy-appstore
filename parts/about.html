About this project

A simpler way to discover what Omarchy can install.

What is this?

The Unofficial Omarchy App Store turns the official package repository into a friendly, searchable directory. It does not host or sell software—it helps people understand what is available, then gives them the real Omarchy install command.

Built by Jessyka

@jessyka_boat

Jessyka is an operations leader by day and an independent software builder by night. She builds practical tools in public, shares the honest process behind them, and created this directory to make the Omarchy ecosystem easier for everyone to explore.
